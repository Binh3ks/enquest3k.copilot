# BAR MODEL GENERATION GUIDE - WEEK 16+

## Overview

Bar models are the required visual support for Singapore Math items in `singapore_math.js` from Week 16 onward.

Current official workflow:
- Prompt files are only for vocab, word_power, and covers.
- Bar models are generated by code, not by image prompts.
- Generation happens from `tools/generate_logiclab_barmodels.py` using each item's `type`, `question_en`, `bar_model`, and answer data.

## Current Production Flow

1. Create or update `src/data/weeks/week_XX/singapore_math.js` and `src/data/weeks_easy/week_XX/singapore_math.js`.
2. Ensure every item has a valid `bar_model` path pointing into `public/images/weekXX/`.
3. Run:

```bash
python3 tools/generate_logiclab_barmodels.py XX
```

4. Verify generated JPG files exist on disk.
5. Upload week images to R2.

This step is already wired into `tools/mass_production_final.sh` as the Logic Lab bar-model generation step.

## Supported Singapore Math Types

The generator currently renders these structures:
- `part_whole`
- `comparison`
- `missing_part`
- `groups`
- `before_after`

If a new `type` is introduced in `singapore_math.js`, update the generator before using it in production.

## Required Data Rules

Each Singapore Math item should include:
- a clear word problem in `question_en`
- a `type` that matches the intended Singapore Math structure
- a `bar_model` path with a versioned filename
- a valid answer string the generator can display in the footer

Example filename pattern:

```text
/images/week21/barmodel_w21_adv_p1_v2.jpg
/images/week21/barmodel_w21_easy_p3_v1.jpg
```

Version the filename whenever the diagram changes meaningfully so CDN caches do not serve stale visuals.

## Validation Checklist

Before upload:
- confirm every `bar_model` file exists on disk
- confirm filenames are versioned
- confirm the diagram matches the underlying math structure
- confirm Advanced and Easy use their correct own `bar_model` paths

After upload:
- verify referenced URLs are reachable on CDN
- verify the displayed image matches the current problem wording

## Curriculum Rules From Week 22+

From Week 22 onward:
- Singapore Math difficulty must scaffold upward by week
- Advanced mode must be clearly harder than Easy in both math structure and language
- word problems should increase in linguistic density and reasoning load in line with the blueprint
- bar models must remain readable and instructionally aligned even as problem wording becomes harder

## Notes

- Do not generate bar model prompts for W20+ workflow.
- Do not keep placeholder text like `"[Bar model image will be generated]"` in production content.
- If the generator cannot represent a required structure, extend the script first instead of falling back to prompt-based image generation.
