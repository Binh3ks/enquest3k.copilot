### **1. TTS Preprocessing Strategy — Separation of Concerns**

#### Problem: Apostrophe Truncation with "o'clock"
- **Symptom**: Dictation read "seven oh /oh/ /oh/" (truncating at apostrophe), while Read station pronounced correctly
- **Root Cause**: Voice-specific behavior:
  - `aura-luna-en` (dictation): Truncates at apostrophes in text
  - `aura-orion-en` (read/shadowing): Handles apostrophes correctly
- **Wrong Solution**: Changing spelling in content files (breaks proper English)
- **✅ Correct Solution**: Preprocessing in `tools/generate_audio_deepgram.py`

#### Implementation (Lines 267-270 in generate_audio_deepgram.py):
```python
def _task(text: str, role: str, filename: str, station: str):
    # TTS preprocessing happens HERE, content files stay pristine
    text = text.replace("o'clock", "o clock")  # Remove apostrophe for TTS
    # ... send to Deepgram API
```

#### Key Principle: **Content vs Audio Preprocessing**
- ✅ **Content files** (vocab.js, mindmap.js): Keep proper spelling ("o'clock")
- ✅ **Audio generation**: Handle TTS quirks via preprocessing
- ✅ **Why**: Content = source of truth; TTS quirks change per voice model
- ❌ **Never**: Pollute content with TTS-specific spellings

#### Reverted Changes:
- Fixed 45 instances across 9 files that had "o clock" → reverted to "o'clock"
- Content files now match Blueprint Phase 1 vocabulary standards

### **3. Vocab Word Audio — Final Consonant Preservation**

#### Problem: Single-Syllable Words Losing Endings
- "lunch" → "lun", "clock" → "clo", "bath" → "ba"

#### Evolution of Fixes:
1. ❌ `word + " ..."` → Still clipped
2. ✅ `word + ". . . . ."` → Period preserves final consonant, spaced dots add trailing silence

#### Current Implementation (Line 317 in generate_audio_deepgram.py):
```python
word = v['word']
# Generate word audio with trailing silence to preserve final sounds
tasks.append(_task(f"{word}. . . . .", 'vocabulary', f"week_{week_num}_vocab_{idx+1}_word", 'vocab'))
```

#### Rule:
> All single-word vocab audio MUST use `word + ". . . . ."` format (period then 5 spaced dots)

### **4. Mindmap Stem Blank Replacement**

#### Problem: Stems with `___` (blanks) caused TTS issues (5 iterations to solve)

#### Failed Attempts:
1. ❌ Skip stems with blanks → No audio generated
2. ❌ Replace `___` with "blank" → TTS reads literally ("seven blank")
3. ❌ Replace with `' ... '` → Glottal stop sounds (unnatural)

#### ✅ Final Solution: Comma + Preprocessing
```python
# In generate_audio_deepgram.py, line ~380:
for stem_text in mindmap_stems:
    t = stem_text.replace('___', ',')  # Natural pause at blank
    t = t.replace("o'clock", "o clock")  # Handle apostrophes
    # Generate audio...
```

#### Rule:
> Mindmap stems: Replace `___` with `,` (comma) for natural pause + apply all TTS preprocessing

## 🔥 NEW IN V5.0 (FEB 25, 2026): CONVERSATION CARD MODE - TRUE STORY ENGINE

**🎯 CRITICAL AI TUTOR UPDATES (ALL Weeks 1-7 FULLY REFACTORED Feb 25, 2026):**

### **0. Conversation Card Mode (skipAI Architecture)**
- **Philosophy**: Story missions KHÔNG cần AI generate responses — câu hỏi đã có sẵn trong `story_arc`
- **Implementation**: `novaEngine.js` pre-computes `nextQuestion` từ `phase_questions`, bypass AI hoàn toàn
- **Result**: Instant response (<1ms), zero LLM cost, zero grammar violations, zero hallucination
- **Flow**: Student submits answer → Engine echoes acknowledgment + delivers next card → No AI call
- **Echo-ack**: `"${lastStudentMsg}! ${nextQuestion}"` — tự động prepend student answer làm ack
- **KHÔNG ảnh hưởng**: Opening turn (turn 0) vẫn dùng opening_narrative từ data; Free Talk vẫn dùng AI

### **Key Files Changed (Feb 25, 2026):**
| File | Change |
|------|--------|
| `novaEngine.js` | Pre-compute nextQuestion → return `{ skipAI: true, directResponse }` |
| `responseGuard.js` | Story character mode: skip fallback recast generation (no "I see!" filler) |
| `StoryMissionTab.jsx` | Use `aiResponse.ai_response` directly (not mangled `combined`) |

### **1. Turn Limit: ALL Story Missions → min=10, max=12** *(Updated Feb 25, 2026)*
- **OLD**: Mission 1: 15-20 turns; Mission 2 & 3: 12-18 turns
- **NEW**: ALL missions: `minimum_turns: 10, maximum_turns: 12`
- **Rationale**: Card Mode delivers clean 10-12 turn conversations; longer missions không cần thiết
- **Implementation**: Tất cả week_01 → week_07 đã được cập nhật

### **2. CRITICAL RULE — Position 0% of mission_context** *(Updated Feb 25, 2026)*
- **Rule**: Dòng ĐẦU TIÊN của mọi `mission_context` PHẢI là CRITICAL RULE
- **Text (exact)**: `CRITICAL RULE: After EVERY student response, you MUST (1) acknowledge briefly, (2) ask the NEXT question from the story, (3) give 2-3 hint choices: "Say: ___ or ___!" NEVER end a response without a question + choices. LAST TURN (turn 12) ONLY: short goodbye + what student learned. No more questions.`
- **Why**: Engine reads mission_context → AI (nếu được gọi) sẽ thấy rule ngay từ ký tự đầu tiên → compliance cao nhất

### **3. mission_context Format: Single Continuous String** *(Updated Feb 25, 2026)*
- `mission_context` là **một string liên tục KHÔNG có newlines** — tất cả sections viết inline cách nhau bằng space.
- **Cấu trúc bắt buộc (theo thứ tự):**
  ```
  CRITICAL RULE → [Title + Week info] → STUDENT PROFILE → CHARACTER → STORY FLOW / GAME MECHANIC →
  LANGUAGE RULES → GRAMMAR FOCUS → VOCABULARY → RECAST ERRORS → FORBIDDEN → filler ban → last turn rule
  ```
- **FORBIDDEN section PHẢI bao gồm:** modal verbs không cần thiết (must, should, need to), off-topic questions (colors, feelings, preferences), filler words ("I see!", "Interesting!", "Great question!", "That's wonderful!")
- **Why**: Ngăn AI thêm filler words ("Nice! I see!") trước card text — làm hỏng echo-ack. Single-string format khớp đúng với Week 5/6/7 battle-tested format.

### **Rule 5: Strict AI Control - NO Off-Topic Questions**

**🚨 CRITICAL LEARNING FROM WEEK 6 & 7 FIXES:**

**❌ AI TUYỆT ĐỐI KHÔNG được hỏi:**
- "Do you like...?" (về preferences)
- "What color is...?" (về descriptions)
- "How are you?" (về feelings)
- "What do you think?" (về opinions)
- "Is it big/small/nice?" (về descriptions)
- "Do you want...?" (về desires)

**✅ AI CHỈ được hỏi về Week N Grammar:**
- Week focuses on "There is a..."? → ONLY ask: "What is in your backpack?"
- Week focuses on prepositions? → ONLY ask: "Where is the treasure?"
- Week focuses on A/An? → ONLY ask: "Is this a book or an apple?"

**🎯 Mission Context Template:**
```javascript
mission_context: `...
STRICT FOCUS: [GRAMMAR ONLY] - Every question must be about [grammar focus].
FORBIDDEN: Do NOT ask "Do you like...?", "What color...?", "How are you?", "What do you think?".
ONLY allowed questions: "[List specific question types related to grammar]".
NEVER ask about preferences, feelings, or descriptions - ONLY [GRAMMAR FOCUS].`
```

**🎭 Roleplay Role Reversal:**
- **OLD WRONG WAY:** AI asks yes/no questions → Student gives short answers
- **NEW CORRECT WAY:** AI asks questions requiring grammar → Student produces full sentences

**Example (Prepositions Week):**
- ❌ BAD: AI: "Is the treasure under the box?" → Student: "Yes"
- ✅ GOOD: AI: "Where is the treasure? Say: The treasure is ON the desk" → Student produces preposition sentence

**Example ("There is a..." Week):**
- ❌ BAD: AI: "Do you have a pen?" → Student: "Yes, I do"
- ✅ GOOD: AI: "(Point 👉 at pen) What is this? Say: There is a pen" → Student produces "There is a..." sentence

**Full Scaffolding Mandatory:**
- EVERY question must have: "Say: [example sentence]"
- Student speaks 70%+ of the time
- AI's job: Elicit language, not dominate conversation

**Why This Rule Exists:**
Week 6 & 7 initially had AI going off-script, asking about colors, preferences, feelings → Students gave yes/no answers instead of practicing grammar → Content was FIXED by adding strict mission_context and reversing roleplay roles → This rule ensures ALL future weeks have this protection built-in from the start.

### **GAMES** (4 Fixed - Auto-adapt Vocabulary)

**1. Word Chain** - Link words by last/first letter

**🎯 20 Questions Design Principles** (Updated Jan 2026):
- **20 rounds** (not 40 - too long for ESL kids)
- **Clue-based, not pure mystery**: AI gives 2 hints upfront
  - Format: "in the [room]. It has [feature]. You [action]."
  - Example: "table: in the kitchen. It has 4 legs. You eat on it."
- **10 allowed objects only**: bed, sofa, lamp, table, chair, mirror, rug, door, window, shelf
- **Why gentle hints?** ESL learners need scaffolding, not frustration
- **Validation**: grammarGuard.js checks "Round X/20" format
- **Post-processing**: responseParser.js auto-fixes if AI forgets new object

**🎯 NATURAL CONVERSATION PRINCIPLES** (Critical for ESL):

1. **Build on student answers** - Don't ignore what they said:
   - ❌ WRONG: "I design bedrooms! What color?"
   - ✅ CORRECT: "A bedroom, great choice! Blue walls sound calming. What furniture do you need?"

2. **Give 3+ vocabulary options** in every response:
   - "Do you want a bed, desk, or bookshelf?"
   - "Should it be big, small, or medium?"
   - "Modern style, classic style, or colorful style?"

3. **Student speaks 80%, AI speaks 20%**:
   - Keep AI responses SHORT (2-3 sentences max)
   - Always end with open question requiring student to speak

4. **Stay in character** - Don't break roleplay:
   - ❌ "Tell me more! What do you want to talk about?" (generic)
   - ✅ "What color do you want for the walls?" (character-specific)

5. **Auto-end at turn 19** with praise message:
   - "Wonderful job! You practiced so many English words today!"
   - Returns to idle for replay

6. **No turn counter visible** - Let conversation feel natural

 * 2. Word type (people, places, objects, abstract)
 * 3. Logical sentence patterns from syllabus

function getSentenceTemplates(word) {

  // STEP 1: Read week grammar from grammar.js
  // Week 1: Subject Pronouns + Verb to be (I am / She is / It is / This is)
  
  // STEP 2: Apply grammar to word based on word type
  
  // SPECIAL CASE: NAME (abstract noun - no emoji)

    return [
      `My name is ___`,      // Student fills in their actual name
      `What is your name?`   // Question form from grammar exercises
    ];

  // PEOPLE: Use "I am a..." / "She is a..." / "He is a..."
  const people = ['student', 'teacher', 'friend', 'scientist'];
  if (people.includes(lowerWord)) {

### **✅ SMARTCHECK VALIDATION (v18.0)**

**Validation Order (CRITICAL - applies to all 3 games):**

1. **Surface Checks FIRST → Reject immediately:**
   - Capital letter at start
   - Proper ending (. ! or ?)
   - If fail → Return error, DON'T proceed to SmartCheck

2. **Content Checks:**
   - Word inclusion (STL: must include target word)
   - Pattern matching (MAS: exact match for unscramble)
   - Frame requirements (ASK: question word detection)

3. **SmartCheck Grammar Analysis (mode: 'critical'):**
   - Status: 'perfect', 'warning', 'incorrect'
   - In 'critical' mode: 'warning' = REJECT (strict!)
   - Rejects grammar errors like "this are my chair"
   - Returns detailed feedback messages

4. **Pass only if ALL checks succeed**

**Example Validation (Show & Tell Ladder, Step 3):**
```javascript
validateInput(userInput) {
  const clean = userInput.trim();
  
  // 1. Surface checks first
  if (!startsWithCapital(clean)) {
    return { correct: false, message: 'Start with a capital letter' };
  }
  if (!hasProperEnding(clean)) {
    return { correct: false, message: 'End with . ! or ?' };
  }
  
  // 2. Content checks
  if (!includesWord(clean, targetWord)) {
    return { correct: false, message: 'Include the word' };
  }
  if (!meetsMinLength(clean, 5)) {
    return { correct: false, message: 'Make a complete sentence' };
  }
  
  // 3. SmartCheck validation
  const smart = analyzeAnswer(clean, clean, 'critical');
  if (smart.status === 'warning' || smart.status === 'incorrect') {
    return { correct: false, message: smart.message };
  }
  
  // 4. Pass
  return { 
    correct: true, 
    message: '✓ Perfect! You said "chair". Now add a detail!' 
  };
}
```
