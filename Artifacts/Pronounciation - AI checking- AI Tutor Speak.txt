❌ SAI LẦM PHỔ BIẾN:

✅ SỰ THẬT:
- Gemini API (qua AI Studio/Vertex AI) KHÔNG nhận direct audio input
- Chỉ hỗ trợ: Text, Images, Video (không có pure audio endpoint)
- Web UI của AI Studio có thể test audio, nhưng không expose qua API
- Multimodal = text + image + video (không bao gồm standalone audio analysis)

→ KẾT LUẬN: Không thể dùng Gemini trực tiếp để analyze audio pronunciation!

1. PHƯƠNG ÁN HIỆN TẠI (MVP - ĐANG CHẠY)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🏗️ KIẾN TRÚC:
Browser Web Speech Recognition API (FREE)
  ↓ (transcript + confidence score)
Gemini 2.0 Flash Exp via AI Studio (FREE)
  ↓ (text comparison & evaluation)
Vietnamese feedback for students

💰 CHI PHÍ: $0

✅ ƯU ĐIỂM:
- Hoàn toàn miễn phí
- Không cần backend audio processing
- Latency thấp (realtime recognition)
- Đủ tốt cho 80-90% trường hợp cơ bản

❌ HẠN CHẾ:
- Chỉ đánh giá text matching, không analyze âm thanh thực
- Phụ thuộc vào browser support (Chrome/Edge only)
- Confidence scores không chi tiết như professional STT
- Không phát hiện được lỗi phát âm subtle (vd: /th/ vs /s/)

📊 PHẠM VI ÁP DỤNG:
- Vocabulary practice: ⭐⭐⭐⭐⭐ (Xuất sắc)
- Simple sentence repetition: ⭐⭐⭐⭐ (Tốt)
- Pronunciation correction: ⭐⭐⭐ (Khá - chỉ detect major errors)

2. PHƯƠNG ÁN HYBRID (KHUYẾN NGHỊ CHO PRODUCTION)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🏗️ KIẾN TRÚC:
95% Cases: Browser Speech Recognition (confidence ≥ 0.7)
  ↓
Gemini Flash - Quick evaluation (FREE)

5% Cases: Words khó hoặc confidence < 0.7
  ↓
Capture audio → OpenAI Whisper API ($0.006/min)
  ↓ (detailed transcript + phoneme confidence)
Gemini Flash - Deep analysis với pronunciation tips

💰 CHI PHÍ THỰC TẾ (100k requests/month):
- 95k requests: Browser + Gemini = $0
- 5k requests × 30s avg = 2,500 phút
- Whisper cost: 2,500 × $0.006 = $15/month
- Gemini calls: Vẫn trong free tier (1.5M/day limit)

📊 TOTAL: ~$15/month cho 1,000 active students

✅ ƯU ĐIỂM:
- Cân bằng tốt giữa chi phí và chất lượng
- 95% cases vẫn free và fast
- 5% difficult cases được analyze sâu với Whisper
- Dễ dàng scale up khi cần
- Có thể detect pronunciation errors chi tiết hơn

❌ HẠN CHẾ:
- Cần thêm backend logic để route requests
- Cần handle audio recording & upload
- Latency cao hơn cho 5% cases (1-2s)

🔧 IMPLEMENTATION:
```javascript
if (browserConfidence < 0.7 || isDifficultWord) {
  // Capture audio blob
  const audioBlob = await recorder.stop();
  
  // Send to Whisper API
  const whisperResult = await openai.audio.transcriptions.create({
    file: audioBlob,
    model: "whisper-1",
    language: "en"
  });
  
  // Deep analysis với Gemini
  const analysis = await gemini.analyze({
    target: targetWord,
    spoken: whisperResult.text,
    confidence: whisperResult.confidence
  });
} else {
  // Quick evaluation với browser transcript
  const analysis = await gemini.quickCheck(browserTranscript);
}
```

Client captures audio → Upload to EngQuest Server
  ↓
Self-hosted Whisper Small Model (on VPS/Cloud)
  ↓ (unlimited transcriptions)
Gemini Flash API - Evaluation & Feedback (FREE in limit)

💰 CHI PHÍ CỐ ĐỊNH:
- VPS Server (2GB RAM): $5-10/month (DigitalOcean/Vultr)
- Gemini API: $0 (free tier)
- TOTAL: ~$10/month cho UNLIMITED pronunciation checks

✅ ƯU ĐIỂM:
- Chi phí cố định, không tăng theo usage
- Full control over model & data
- Có thể fine-tune Whisper cho giọng Việt-Anh
- Latency thấp nếu server gần users
- Privacy tốt nhất (data không ra khỏi server)

❌ HẠN CHẾ:
- Cần setup & maintain server
- Cần kiến thức DevOps (Docker, deployment)
- Cần monitor uptime & performance

🔧 TECH STACK:
```yaml
Docker Container:
  - Whisper Small Model (faster-whisper)
  - FastAPI backend
  - Redis for caching
  
Deployment:
  - DigitalOcean Droplet (2GB RAM)
  - Nginx reverse proxy
  - Auto-scaling nếu cần

Estimated Performance:
  - ~100 concurrent users
  - Processing time: 0.5-1s per 30s audio
  - 99.9% uptime với monitoring
```

🎯 LỘ TRÌNH KHUYẾN NGHỊ:

▸ PHASE 1: MVP (0-100 users) - HIỆN TẠI ✅
  Công nghệ: Browser Speech Recognition + Gemini Flash
  Chi phí: $0
  Timeline: Đã hoàn thành
  Mục tiêu: Validate product-market fit

▸ PHASE 2: Growth (100-1,000 users) - 1-2 THÁNG
  Công nghệ: Hybrid (Browser + Whisper API cho 5% cases)
  Chi phí: ~$15-30/month
  Timeline: Khi có 100+ active users
  Mục tiêu: Improve accuracy cho difficult words
  
▸ PHASE 3: Scale (1,000-10,000 users) - 3-6 THÁNG
  Công nghệ: Self-hosted Whisper + Gemini
  Chi phí: $10-50/month (fixed)
  Timeline: Khi có 1,000+ daily active users
  Mục tiêu: Cost optimization & full control

▸ PHASE 4: Enterprise (10,000+ users) - 6-12 THÁNG
  Công nghệ: Multi-region deployment + caching layer
  Chi phí: Scale theo infrastructure needs
  Timeline: Series A funding
  Mục tiêu: 99.99% uptime, sub-second latency
