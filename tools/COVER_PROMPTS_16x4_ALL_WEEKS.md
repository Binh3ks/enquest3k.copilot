# Cover Image Prompts — All 29 Weeks (16:4 Banner Format)

## HOW TO USE
- Generator: ChatGPT → "Create image", or Midjourney, or any AI image tool
- **CRITICAL — aspect ratio setting**: Select **"wide/landscape"** or add `--ar 4:1` (Midjourney)
- For ChatGPT DALL-E: type the prompt, then explicitly say "Generate in ultra-wide 4:1 landscape format"
- Style to use consistently: **2D cartoon illustration, vibrant saturated colors, soft warm lighting, clean educational style for children ages 8–12, full-width panoramic scene, NO text or words anywhere in the image**
- Each cover = 1 wide banner image. Left side → right side should tell a story or show a connected scene.

## GENERATION TIPS

### Forcing 16:4 (4:1) Ratio
- **ChatGPT / DALL-E 3**: Say "Landscape format, extremely wide, 4:1 aspect ratio" at the start of every prompt
- **Midjourney**: Add `--ar 4:1` at the end of every prompt
- **Adobe Firefly**: Select "4:1" from the aspect ratio dropdown before generating
- **Ideogram**: Select custom ratio 2048x512 or 2048×448

### Recommended Output Size
- Target: **2048 × 512 pixels** (exact 4:1 = 16:4)
- Minimum: **1792 × 448 pixels**

### Style Keywords to Add to Any Prompt
`2D cartoon illustration, vibrant saturated colors, soft studio lighting, educational illustration style for children ages 8-12, panoramic wide-angle view, NO text or words in image, seamless left-to-right composition, all scene elements fully visible within frame`
