## 🚀 BƯỚC TIẾP THEO

### Làm theo hướng dẫn trong file `HƯỚNG_DẪN_DEPLOY.md`

Hoặc làm theo đây (tóm tắt):

### BƯỚC 1: Tạo Space (2 phút)
1. Vào: https://huggingface.co/new-space
2. Đăng nhập bằng tài khoản `binh3k`
3. Điền:
   - **Space name**: `Engquest3k`
   - **SDK**: **Docker** ⚠️ QUAN TRỌNG!
   - **Hardware**: **CPU basic - FREE**
   - **Visibility**: Public
4. Click **Create Space**

### BƯỚC 2: Upload Files (3 phút)
1. Trong Space vừa tạo, click **Files** tab
2. Click **Add file** → **Upload files**
3. Upload **4 files** này (KHÔNG upload HƯỚNG_DẪN_DEPLOY.md):
   - ✅ Dockerfile
   - ✅ app.py
   - ✅ requirements.txt
   - ✅ README.md
4. Mỗi file commit message: "Add [tên file]"
5. Click **Commit to main** sau mỗi file

### BƯỚC 3: Đợi Build (5-10 phút)
1. Sau khi upload file cuối, HF tự động build
2. Click tab **Logs** để xem progress
3. Đợi đến khi thấy: `✅ Kokoro TTS ready`
4. Status chuyển thành **Running** (màu xanh)

### BƯỚC 4: Test (1 phút)
Mở trình duyệt, test URL này:
```
https://binh3k-engquest3k.hf.space/health
```

Phải thấy response:
```json
{
  "status": "ok",
  "kokoro": "loaded"
}
```

Test giọng đọc:
```
https://binh3k-engquest3k.hf.space/tts?text=Hello&station=read
```
→ Trình duyệt sẽ download file MP3, mở và nghe thử!
