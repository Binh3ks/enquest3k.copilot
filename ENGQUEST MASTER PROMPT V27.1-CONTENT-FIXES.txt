## II. AI RESPONSE FORMAT - COMMON FAILURES

### Problem 1: Missing ACK (Acknowledgment)

**Console Evidence**:
```
⚠️ responseParser: Response too short (0 chars)
⚠️ AI missing ACK, using fallback: Great!
```

**What's Happening**:
AI returns JSON with empty or missing `teacher_ack` field:

```javascript
// WRONG:
{
  "teacher_ack": "",  // ❌ Empty!
  "teacher_recast": "Your mother cooks!",
  "teacher_question": "Does she cook breakfast?",
  "suggested_hints": ["Yes", "she", "cooks"]
}

// CORRECT:
{
  "teacher_ack": "Great!",  // ✅ Has content
  "teacher_recast": "Your mother cooks!",
  "teacher_question": "Does she cook breakfast?",
  "suggested_hints": ["Yes", "she", "cooks"]
}
```

**Impact**:
- Response Guard must inject fallback ACK ("Great!")
- Student doesn't get proper acknowledgment
- Response feels generic and cold

**Fix for Prompt Instructions**:
```
YOU MUST ALWAYS provide a non-empty teacher_ack field.
Valid examples: "Great!", "Wonderful!", "Good job!", "Nice!", "Excellent!"
NEVER return teacher_ack: "" (empty string)
```

### Problem 2: Missing RECAST

**Console Evidence**:
```
⚠️ AI missing RECAST, using empty recast (ACK only)
```

**What's Happening**:
AI returns empty `teacher_recast` when student makes grammar mistakes:

```javascript
Student: "I have mother"

// WRONG:
{
  "teacher_ack": "Great!",
  "teacher_recast": "",  // ❌ Empty! Should model correct grammar
  "teacher_question": "What does your mother do?",
  "suggested_hints": ["She", "works", "cooks"]
}

// CORRECT:
{
  "teacher_ack": "Great!",
  "teacher_recast": "You have a mother!",  // ✅ Models "a mother"
  "teacher_question": "What does your mother do?",
  "suggested_hints": ["She", "works", "cooks"]
}
```

**Impact**:
- Student doesn't learn correct grammar
- No modeling of proper English structure
- Misses teaching opportunity

**Fix for Prompt Instructions**:
```
YOU MUST provide teacher_recast that:
1. Echoes student's content
2. Corrects any grammar errors naturally
3. Models proper English structure
4. Uses complete sentences

If student's answer is already perfect, recast can repeat the same sentence.
NEVER return teacher_recast: "" unless student's grammar is 100% perfect.
```

### Problem 3: Missing or Irrelevant Hints

**Console Evidence**:
```
⚠️ responseParser: Question asked but no hints provided
```

**What's Happening**:
AI returns empty hints array or hints unrelated to the question:

```javascript
Question: "What does your mother do in the morning?"

// WRONG:
{
  "suggested_hints": []  // ❌ Empty!
}

// WRONG:
{
  "suggested_hints": ["I", "am", "have", "like", "my", "is"]  // ❌ Generic, not relevant!
}

// CORRECT:
{
  "suggested_hints": ["She", "wakes", "cooks", "cleans", "works"]  // ✅ Relevant actions
}
```

**Impact**:
- Students have no scaffolding for answers
- Hint buttons show useless words
- Conversation flow breaks

**Fix for Prompt Instructions**:
```
YOU MUST provide suggested_hints that:
1. Are 5-6 words DIRECTLY relevant to the question asked
2. Match the expected answer structure
3. Use vocabulary from the current week's theme
4. Progress from simple to more specific

Example:
Q: "What does your mother do?"
Hints: ["She", "cooks", "works", "cleans", "helps"] ✅

Q: "Where does your father work?"
Hints: ["He", "works", "at", "office", "home"] ✅

NEVER provide generic hints like ["I", "am", "is", "have", "the"]
ALWAYS match hints to the specific question context.
```

### Problem 4: Response Too Short

**Console Evidence**:
```
⚠️ responseParser: Response too short (0 chars)
```

**What's Happening**:
Sometimes AI returns completely empty responses or only partial fields:

```javascript
// WRONG - Causes crash:
{
  "teacher_ack": "",
  "teacher_recast": "",
  "teacher_question": "",
  "suggested_hints": []
}

// WRONG - Missing fields:
{
  "teacher_question": "What does she do?",
  "suggested_hints": ["She", "works"]
  // Missing teacher_ack, teacher_recast!
}
```

**Fix for Prompt Instructions**:
```
YOU MUST ALWAYS return a complete JSON object with ALL fields:
{
  "teacher_ack": "non-empty string",
  "teacher_recast": "non-empty string or same as ack if perfect",
  "teacher_question": "non-empty question string",
  "suggested_hints": ["word1", "word2", "word3", "word4", "word5"],
  "mission_status": "continue" or "completed",
  "current_turn": number,
  "total_turns": number
}

NEVER omit any field. NEVER return empty strings for required fields.
```

## III. RESPONSE GUARD FALLBACK MECHANISMS

### What is Response Guard?

**File**: `src/services/ai_tutor/utils/responseGuard.js`

**Purpose**: Validates and fixes AI responses before showing to students

**Console Logs You'll See**:
```
🔒 ResponseGuard (Legacy): stepKey=mother_morning | canonical="What does your mother do in the morning?"
🔍 Response format: Legacy
⚠️ AI missing ACK, using fallback: Great!
⚠️ AI missing RECAST, using empty recast (ACK only)
🔒 Forced canonical (Legacy): stepKey=mother_busy | question="Is your mother busy?"
✅ Using canonical hints from step definition (Legacy mode): (5) ['Yes', 'she', 'is', 'busy', 'works']
🎯️ Enforced Ms. Nova structure: {ack: 'Great!', recast: '(none)', ...}
🛡️ Response guard: Validated response
```

### When Fallbacks Activate

**Scenario 1: Empty ACK**
```javascript
AI Returns: { teacher_ack: "", ... }
Guard Action: Injects "Great!" as fallback
Console: "⚠️ AI missing ACK, using fallback: Great!"
```

**Scenario 2: Empty RECAST**
```javascript
AI Returns: { teacher_recast: "", ... }
Guard Action: Uses ACK content as recast
Console: "⚠️ AI missing RECAST, using empty recast (ACK only)"
```

**Scenario 3: Wrong Question**
```javascript
AI Returns: { teacher_question: "How are you?", ... }  // Off-topic!
Guard Action: Forces canonical question from turnManager
Console: "🔒 Forced canonical (Legacy): stepKey=mother_work | question='Where does your mother work?'"
```

**Scenario 4: Bad Hints**
```javascript
AI Returns: { suggested_hints: ["um", "well"], ... }  // Only 2 hints, useless!
Guard Action: Uses canonical hints from turnManager definition
Console: "✅ Using canonical hints from step definition (Legacy mode): (5) ['She', 'works', 'at', 'home', 'office']"
```

### Why This Matters for Mass Production

**Problem**: If AI consistently returns bad responses, Response Guard will ALWAYS override with canonical fallbacks. This means:
- AI is not actually generating content
- System falls back to hardcoded questions/hints
- Students get repetitive, robotic experience

**Solution**: Fix the AI PROMPT and RESPONSE FORMAT requirements so Response Guard RARELY needs to activate.

**Goal Metrics**:
- ✅ Response Guard fallback rate < 5% of turns
- ✅ Most turns use AI-generated content
- ❌ Response Guard fallback rate > 50% = AI prompt is broken

## IV. V27 JSON FORMAT REQUIREMENTS (STRICT)

### Complete Response Schema

```javascript
{
  // REQUIRED FIELDS - NEVER EMPTY
  "teacher_ack": "Great! | Wonderful! | Excellent! | Good job! | Nice!",
  
  "teacher_recast": "Complete sentence echoing student's answer with grammar corrections",
  
  "teacher_question": "Open-ended question to continue conversation",
  
  "suggested_hints": [
    "word1",  // Most basic/common word
    "word2",  // Related to expected answer
    "word3",  // Specific to context
    "word4",  // More advanced option
    "word5"   // Alternative phrasing
  ],
  
  // MISSION STATUS (Story Mission only, FreeTalk can omit)
  "mission_status": "continue" | "completed",
  
  // TURN TRACKING (Story Mission only)
  "current_turn": 2,      // Current turn number
  "total_turns": 15       // Total turns in mission
}
```

### Field-by-Field Requirements

#### `teacher_ack` (REQUIRED)
- **Type**: String, 1-20 words
- **Content**: Brief acknowledgment of student's answer
- **Examples**: 
  - ✅ "Great!"
  - ✅ "Wonderful!"
  - ✅ "Good job!"
  - ✅ "That's nice!"
  - ❌ "" (empty)
  - ❌ "I heard you" (generic)
- **Rule**: MUST be non-empty, MUST be encouraging

#### `teacher_recast` (REQUIRED)
- **Type**: String, 3-20 words
- **Content**: Student's answer recast with correct grammar
- **Examples**:
  - Student: "I have mother" → ✅ Recast: "You have a mother!"
  - Student: "My family big" → ✅ Recast: "Your family is big!"
  - Student: "She cook" → ✅ Recast: "She cooks!"
  - ❌ "" (empty)
  - ❌ "I heard you" (not recasting)
- **Rule**: MUST model correct grammar, MUST echo student's content

#### `teacher_question` (REQUIRED)
- **Type**: String, 5-20 words
- **Content**: Open-ended follow-up question
- **Examples**:
  - ✅ "What does your mother do in the morning?"
  - ✅ "Where does your father work?"
  - ✅ "Do you have brothers or sisters?"
  - ❌ "How are you?" (too generic)
  - ❌ "Yes?" (not a question)
- **Rule**: MUST be relevant to mission topic, MUST be open-ended

#### `suggested_hints` (REQUIRED)
- **Type**: Array of 5-6 strings
- **Content**: Words to help student answer the question
- **Examples**:
  - Q: "What does your mother do?" → ✅ Hints: ["She", "cooks", "works", "cleans", "helps"]
  - Q: "Where is your school?" → ✅ Hints: ["My", "school", "is", "near", "far"]
  - ❌ [] (empty)
  - ❌ ["um", "well"] (only 2 words, useless)
  - ❌ ["I", "am", "is", "the", "a"] (generic grammar words)
- **Rule**: MUST be 5-6 words, MUST be relevant to question, MUST help construct answer

#### `mission_status` (CONDITIONAL)
- **Type**: String enum
- **Values**: "continue" | "completed"
- **When**: Story Mission only (FreeTalk can omit)
- **Logic**:
  - "continue" = More questions to ask
  - "completed" = Reached turn 15/15 or student asked to end
- **Rule**: Set "completed" ONLY when turn_count >= 15 OR student explicitly ends

#### `current_turn` / `total_turns` (CONDITIONAL)
- **Type**: Numbers
- **When**: Story Mission only
- **Example**: `"current_turn": 3, "total_turns": 15`
- **Rule**: Track progress through mission steps

## VII. TROUBLESHOOTING GUIDE

### Symptom: Console shows "⚠️ AI missing ACK"

**Cause**: `teacher_ack` field is empty or missing

**Fix**: Update system prompt to require non-empty ACK:
```javascript
systemPrompt += `
YOU MUST provide a non-empty teacher_ack.
Valid options: "Great!", "Wonderful!", "Excellent!", "Good job!", "Nice!"
`;
```

---

### Symptom: Console shows "⚠️ AI missing RECAST"

**Cause**: `teacher_recast` field is empty

**Fix**: Update prompt to emphasize recast importance:
```javascript
systemPrompt += `
YOU MUST echo the student's answer in teacher_recast with correct grammar.
Example:
Student: "I have mother"
teacher_recast: "You have a mother!"
`;
```

---

### Symptom: Console shows "🔒 Forced canonical"

**Cause**: AI's question doesn't match expected canonical question

**Fix**: Add canonical question explicitly to prompt:
```javascript
systemPrompt += `
YOU MUST ask this EXACT question: "${currentStep.canonical}"
Do not rephrase or change the question.
`;
```

---

### Symptom: Hints are generic words like "I, am, is"

**Cause**: AI generating hints from scratch instead of using canonical

**Fix**: Provide exact hints in prompt:
```javascript
systemPrompt += `
YOU MUST use EXACTLY these hints: ${JSON.stringify(currentStep.hints)}
Do not generate different hints.
`;
```

---

### Symptom: Response Guard activates every turn

**Cause**: AI responses consistently fail validation

**Fix**: Review entire system prompt structure. Ensure:
1. Clear format instructions at TOP of prompt
2. Example responses provided
3. Forbidden patterns explicitly listed
4. Field requirements stated as "MUST" not "should"
