### **Rule 2: Follow STEP 2 Validation Checklist**

**Before saving ANY AI Tutor file, verify:**

✅ **Structure Validation** (20 items)
- Metadata: week_id, title, theme, grammar_pattern
- 10 vocabulary objects (not strings)
- 3 missions with correct turn limits
- 4 phases per mission (intro → main → deeper → conclusion)

- Word Chain, 20 Questions, Sentence Builder configured
- All games use Week N vocabulary ONLY

**Total: 38 validation points** - ALL must pass

### **Rule 3: Update gameAdaptation.js**

**Every new week MUST add entry:**
```javascript
// File: src/config/gameAdaptation.js
export const GAME_TEMPLATES = {
  5: { ... }, // Week 5 template
  N: { // ← ADD THIS!

    games: { word_chain: {...}, twenty_questions: {...}, sentence_builder: {...} }
  }
};
```

**Without this:** Games will use wrong vocabulary (Week 5 words)

**All 6 must pass** - No exceptions
