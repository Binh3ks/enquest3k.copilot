## 📚 SECTION I: VIETNAMESE CONTENT STRATEGY (70/30 MIXED)

### 1.1 Philosophy: Balanced Context

**Ratio:** 70% Universal / 30% Vietnamese

**Rationale:**
- ✅ **Scalability:** 70% content reusable for Thailand/Indonesia versions
- ✅ **Cultural relevance:** 30% Vietnamese = meaningful connection for VN students
- ✅ **Cognitive load:** Familiar context (30%) reduces extraneous load
- ✅ **Competitive positioning:** "International standard + Vietnamese heart"

---

### 1.2 Vietnamese Content Selection Guidelines

#### ✅ USE Vietnamese Context When:

**1. Geographic Concepts Better Illustrated with VN Examples:**
```
Universal: "Rivers flow from mountains to sea"
Vietnamese Integration: "The Mekong River flows from Tibet through Vietnam to the South China Sea, splitting into 9 tributaries in the Mekong Delta."

Why: Concrete, regional, students may have visited/seen Mekong Delta
```

**2. Historical Parallels Strengthen Understanding:**
```
Universal: "Ancient civilizations built near rivers"
Vietnamese Integration: "Ancient people in Vietnam built settlements near the Red River and Mekong River, just like Ancient Egyptians built near the Nile."

Why: Connects universal pattern to local example
```

**3. Biodiversity/Ecology Unique to Vietnam:**
```
Universal: "Endangered species need protection"
Vietnamese Integration: "The Saola (Vietnamese unicorn) is one of the world's rarest mammals, found only in Vietnam and Laos."

Why: Endemic species, national pride, conservation case study
```

**4. Engineering/Technology with VN Historical Significance:**
```
Universal: "People use tools to solve problems"
Vietnamese Integration: "Vietnamese farmers built bamboo water wheels (Noria) to irrigate rice fields for centuries."

Why: Traditional engineering, sustainable materials
```

#### ❌ AVOID Vietnamese Context When:

**1. Universal Example More Globally Known:**
```
❌ DON'T: Replace "Ancient Egypt pyramids" with "Vietnamese temples"
✅ DO: Teach pyramids (universal), THEN mention Vietnamese architecture as parallel
```

**2. Pronunciation Too Difficult for English Learning:**
```
❌ DON'T: "Trần Hưng Đạo" (hard pronunciation)
✅ DO: "Vietnamese King" or "a famous Vietnamese general"
```

**3. Too Niche (Urban/Rural Divide):**
```
❌ DON'T: "Cần cẩu tre" (bamboo crane - rural kids know, urban don't)
✅ DO: "Lever = Seesaw" (universal playground experience)
```

### 2.5 Debate Progression (W40 → W67 → W121)

#### Phase 1+ (W40-54): Micro-Debate

**Structure:** 1 Opinion + 1 Reason  
**Grammar:** Comparative (stronger than, faster than)  
**Topics:** Aligned with weekly theme (animals, food, weather, toys)

**Example W45 Debate:**
- Week theme: Ancient Civilizations
- Debate: "Which was more advanced: Ancient Egypt or Ancient Rome?"
- Student: "Egypt because pyramids are bigger."
- AI: "But Rome had better roads and aqueducts!"

---

#### Phase 2 (W67-120): OREO Debate

**Structure:** Opinion - Reason - Evidence - Opinion  
**Grammar:** Comparative + Sequencing (First, Second, Finally)  
**Topics:** Technology, habits, preferences

**Example W67 Debate (from current Blueprint):**
- Topic: "Paper or Email - which is better?"
- Student: "I prefer email. First, it's faster than paper. For example, I can send a message in one second. Second, it saves trees. That's why email is better."
- AI: "But paper feels more personal!"
- Student: "Yes, but efficiency matters more today."

---

#### Phase 3 (W121+): Formal Debate

**Structure:** Thesis - Arguments (3) - Counter-argument - Conclusion  
**Grammar:** Full range (conditionals, modals, passive voice)  
**Topics:** Social issues (homework, video games, technology)

**Example W121 Debate:**
- Topic: "Is homework beneficial for students?"
- Student: Full argumentation (5-7 minutes speech)
- AI: Challenges with counter-examples
- Student: Rebuts counter-arguments

import React, { useState, useEffect } from 'react';

export default function DebateCorner({ weekData, studentId }) {
  const [debateState, setDebateState] = useState('not_started'); // 'not_started', 'active', 'ended'
  const [messages, setMessages] = useState([]);
  const [turn, setTurn] = useState(0);
  
  const startDebate = async () => {
    const response = await fetch('/api/ai-tutor/debate/start', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ week: weekData.week, student_id: studentId })
    });

    setMessages([{
      from: 'ai',
      text: data.opening_message,
      avatar: data.ai_persona.avatar_url
    }]);
    
    setDebateState('active');
  };
  
  const sendStudentResponse = async (input) => {
    // Add student message to UI
    setMessages(prev => [...prev, { from: 'student', text: input }]);
    
    // Get AI response
    const response = await fetch('/api/ai-tutor/debate/respond', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        debate_id: currentDebateId,
        student_input: input,
        turn: turn + 1
      })
    });

    setMessages(prev => [...prev, { 
      from: 'ai', 
      text: data.ai_response,
      feedback: data.grammar_feedback
    }]);
    
    setTurn(prev => prev + 1);
    
    // Check if debate should end
    if (!data.continue || turn >= 4) {
      endDebate();

- [ ] **History Timeline** (0-1 question): Chronological order
  - Example: "Which came first: Ancient Egypt or Ancient Rome?"

- [ ] **History Reasoning** (1-2 questions): Cause-effect in history
  - Example: "Why did explorers need compasses?"

- [ ] **Cultural Geography** (0-1 question): Culture + place connection
  - Example: "Why is rice important in Asia?"

- [ ] **Economics/Social Application** (1-2 questions): Real-world use
  - Example: "What crop does the Mekong Delta produce most?"

- [ ] **Comparison** (0-1 question): Compare 2 places/times
  - Example: "How is North Vietnam different from South Vietnam?"

**Balance Rule:** 
- 50% Geography (3-4 questions)
- 30% History (2 questions)
