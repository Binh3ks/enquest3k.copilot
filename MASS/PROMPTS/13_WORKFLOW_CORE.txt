## 📋 5-PHASE EXECUTION PIPELINE

### PHASE 1: SETUP & PREPARATION (5 minutes)

**Step 1.1: Read Syllabus**
```bash
cd /Users/binhnguyen/Downloads/Engquest3k
grep "Week X" src/data/syllabus_database.js
```

Extract:
- week_title_en / week_title_vi
- topic / topic_vi
- target_vocab (7-10 words)
- grammar_pattern
- CEFR level (based on week range)

**Step 1.2: Create Folder Structure**
```bash
mkdir -p src/data/weeks/week_XX
```

**Step 1.3: Determine Week Format**
- Week 1-3 → Use SCHEMA_BASIC (canonical_question)
- Week 4+ → Use SCHEMA_VARIANT (question_variants)

**Tokens Used**: MASTER_ORCHESTRATOR (500) + WORKFLOW_CORE (300) = **800 dòng**

---

### PHASE 2: GENERATE AI TUTOR (10 minutes)

**Step 2.1: Read AI Tutor Prompts**
```
1. V29_AI_TUTOR_CORE.txt (400 dòng)
2. V29_AI_TUTOR_SCHEMA_BASIC.txt OR SCHEMA_VARIANT.txt (300-400 dòng)
3. V29_AI_TUTOR_EXAMPLES.txt (if confused - 600 dòng)
```

**Step 2.2: Generate week_XX_real.js**

Create file at: `/src/data/weeks/week_XX_real.js`

**Structure**:
```javascript
const weekXRealData = {
  // Metadata (Lines 1-100)
  week_id: X,
  ...
  target_vocab: [10 objects],
  
  // Missions (Lines 100-1000)
  story_missions: [3 missions],
  
  // FreeTalk (Lines 1000-1100)
  freetalk_knowledge: { ... }
};

export default weekXRealData;
```

**Step 2.3: Validate**
```bash
node -e "const w = require('./src/data/weeks/week_XX_real.js'); console.log(w.week_id)"
```

Expected output: Week number

**Tokens Used**: 400 + 400 = **800 dòng** (Best case)

**Output**: 1 file (~575-1,099 lines)

---

### PHASE 3: GENERATE 14 ADVANCED STATIONS (20 minutes)

**Step 3.1: Read Station Prompts**
```
1. V29_STATIONS_CORE.txt (300 dòng) ← Already read in Phase 1
2. V29_STATIONS_ADVANCED.txt (600 dòng) ← Read once, reuse for all 14
```

**Step 3.2: Generate 14 Files in Order**

**CRITICAL**: Generate in THIS order (cross-reference dependencies):

```
1. vocab.js          ← FIRST (others depend on this)
2. read.js           ← SECOND (dictation/shadowing depend on this)
3. grammar.js        ← Grammar exercises
4. dictation.js      ← Extract from read.js
5. shadowing.js      ← Same as dictation + audio
6. writing.js        ← Use keywords from vocab.js
7. ask_ai.js         ← Use vocab words
8. logic.js          ← Use theme from read.js
9. explore.js        ← CLIL content
10. mindmap.js       ← Use vocab + grammar
11. word_power.js    ← Use vocab for collocations
12. daily_watch.js   ← Videos matching theme
13. word_match.js    ← Use vocab words
14. video_queries.json ← Questions for videos
```

**Location**: `/src/data/weeks/week_XX/[filename].js`

**Step 3.3: Validate Cross-References**
```bash
# Check vocab is bolded in read.js
grep -o '\*\*[^*]*\*\*' src/data/weeks/week_XX/read.js | wc -l

# Check dictation matches read
wc -l src/data/weeks/week_XX/read.js src/data/weeks/week_XX/dictation.js

# Check all files export
for file in src/data/weeks/week_XX/*.js; do
  node -e "const f = require('$file'); console.log('✓', '$file')"
done
```

**Tokens Used**: 300 + 600 = **900 dòng** (Read once, reuse context)

**Output**: 14 files (~725 lines total)
