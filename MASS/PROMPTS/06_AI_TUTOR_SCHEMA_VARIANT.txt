## OBJECTIVE STRUCTURE DETAILS

### Regular Objective (9 per mission):

```javascript
{
  stepKey: "unique_key",  // Unique identifier (e.g., "student_name", "feeling_today")
  category: "Category",  // E.g., "Identity", "Emotion Expression", "Preferences"
  
  question_variants: [  // 3 variants for replay value
    {
      question: "First way to ask the question?",
      hints: ["word4", "word1", "word6", "word2", "word5", "word3"]  // 6-9 words, SCRAMBLED
    },
    {
      question: "Second way to ask?",
      hints: ["word3", "word5", "word1", "word4", "word2"]  // Different order
    },
    {
      question: "Third way to ask?",
      hints: ["word2", "word4", "word6", "word1", "word3"]  // Different order
    }
  ],
  
  target_keywords: ["keyword1", "keyword2", "keyword3"],  // Words AI looks for in response
  
  ack_variants: ["Great!", "Nice!", "Wonderful!", "Excellent!"],  // 3-5 acknowledgments
  
  recast_templates: [
    "You said {response}!",  // Template with {variable}
    "So you are {response}!"
  ],
  
  success_criteria: "What counts as successful response"  // E.g., "Student says their name"
}
```

### Student Question Invitation (2 per mission):

```javascript
{
  stepKey: "student_question_1",  // or student_question_2
  category: "Student Inquiry",
  type: "invitation",  // ⬅️ CRITICAL: marks as invitation
  
  question_variants: [
    { question: "Do you have any questions for me?", hints: [] },  // Empty hints
    { question: "Is there anything you want to ask?", hints: [] },
    { question: "What would you like to know?", hints: [] }
  ],
  
  target_keywords: [],  // Empty - any question is valid
  
  ack_variants: [
    "Good question!",
    "That's interesting!",
    "I'm glad you asked!"
  ],
  
  recast_templates: [],  // Empty - no recast needed
  
  allow_skip: true,  // ⬅️ Student can skip without penalty
  
  success_criteria: "Student asks a question or skips"
}
```

**Placement**: Insert after every 3-4 regular objectives

### Goodbye Objective (1 per mission, last):

**SPECIAL FORMAT** (different from regular objectives):

```javascript
{
  stepKey: "goodbye",
  category: "Closing",
  type: "termination",  // CRITICAL: Marks mission end for TurnManager
  canonical_question: "",  // Empty string (required field, not used)
  target_keywords: [],  // Empty array
  ack_variants: ["Wonderful!", "Great job!", "Bye!"],
  hints: [],  // Empty array (no hints for goodbye)
  recast_templates: [],  // Empty array
  goodbye_en: "Great job! [Positive message about mission]. Keep [encouragement]. Bye!",
  goodbye_vi: "[Vietnamese goodbye message with encouragement]",
  success_criteria: "Mission complete"
}
```

**Key Differences from Regular Objectives**:
- NO `question_variants` array (uses empty `canonical_question` instead)
- HAS `type: "termination"` field (critical for TurnManager)
- HAS `goodbye_en` and `goodbye_vi` fields (displayed in UI)
- All arrays except `ack_variants` are empty

## HINTS: CRITICAL RULES

### Week 4+ Hints Are FULL SENTENCES:
- **6-9 words** per hint array
- Words from expected answer sentence
- **Scrambled order** (not sentence order!)

**Example**:
Question: "What is your name?"
Expected answer: "My name is Alex."

❌ WRONG (Week 1-3 style):
```javascript
hints: ["My", "name", "is"]  // Only 3 words, individual words
```

✅ CORRECT (Week 4+ style):
```javascript
hints: ["name", "is", "My", "I", "am"]  // 5-6 words, scrambled, includes variations
```

### How to Create Hints:

1. Write expected answer: "My name is Alex I am a student"
2. Extract key words: ["My", "name", "is", "Alex", "I", "am", "a", "student"]
3. Remove student-specific words: ["My", "name", "is", "I", "am"]
4. Scramble: ["name", "is", "My", "I", "am"]
5. Verify 6-9 words (add more if needed)

## MISSION STRUCTURE: 12 Objectives Total

### Typical Mission Breakdown:

```
Objective 1: Regular question (identity)
Objective 2: Regular question (emotion)
Objective 3: Regular question (preference)
Objective 4: Regular question (activity)
↓
Student Question 1: Invitation for student to ask
↓
Objective 5: Regular question (description)
Objective 6: Regular question (comparison)
Objective 7: Regular question (opinion)
Objective 8: Regular question (reason)
↓
Student Question 2: Second invitation
↓
Objective 9: Regular question (summary)
Objective 10: Goodbye
```

**Total**: 9 regular + 2 invitations + 1 goodbye = 12 objectives
