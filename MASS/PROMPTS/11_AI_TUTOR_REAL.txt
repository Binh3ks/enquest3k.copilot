## 📋 SCHEMA SELECTION

### Week 1-3: Basic Schema (Prompt 05)
- Free conversation format
- No objectives array
- default_hints at mission level
- conversation_topics + example_questions
- Field: `free_talk_knowledge` (with underscore)

### Week 4+: Variant Schema (Prompt 06)
- Objective-based structure
- question_variants (3 per objective)
- hints per question (6-9 scrambled words)
- 2 student_question invitations
- goodbye objective
- Field: `freetalk_knowledge` (NO underscore)

**⚠️ CRITICAL**: Read Prompt 05 (Week 1-3) OR Prompt 06 (Week 4+) for complete schema!

## 🎯 FREE TALK 2.0 UPGRADE (ALL WEEKS)

### New Field: starter_prompts (Required)

**Purpose**: Provide UI suggestion chips for 3 interaction modes:
1. **Helper Mode**: Translation/dictionary requests
2. **Gamer Mode**: Interactive language games
3. **Chat Mode**: Open conversation starters

**Format**:
```javascript
freetalk_knowledge: {  // or free_talk_knowledge for Week 1-3
  theme: "...",
  knowledge_base: [...],
  example_opening_questions: [...],
  
  // ✅ NEW FIELD (Required for ALL weeks)
  starter_prompts: [
    { text_en: "Let's play a game! 🎮", text_vi: "Chơi trò chơi đi cô!", type: "game" },
    { text_en: "How do you say 'con cá'? 🐟", text_vi: "Con cá tiếng Anh là gì?", type: "help" },
    { text_en: "I love reading! 📚", text_vi: "Con thích đọc sách!", type: "chat" },
    { text_en: "I play with my friends! 🧱", text_vi: "Con chơi với bạn!", type: "chat" }
  ]
}
```

**Rules**:
- **Count**: Exactly 4 prompts per week
- **Distribution**: 1 game + 1 help + 2 chat
- **text_en**: STUDENT'S statement/question (NOT AI asking!)
- **text_vi**: Friendly Vietnamese, use emojis
- **type**: Must be "game", "help", or "chat"
- **Context**: Adapt to week theme

**CRITICAL - text_en Must Be Student Voice**:
- ✅ "I love drawing!" (student shares)
- ✅ "Let's play a game!" (student initiates)
- ✅ "How do you say 'con mèo'?" (student asks)
- ❌ "What makes you happy?" (AI asks - WRONG!)
- ❌ "Do you like games?" (AI asks - WRONG!)

**Rules**:
- **Count**: Exactly 4 prompts per week
- **Distribution**: 1 game + 1 help + 2 chat
- **text_en**: Simple English (A0 level), natural spoken style
- **text_vi**: Friendly Vietnamese, use emojis
- **type**: Must be "game", "help", or "chat"
- **Context**: Adapt to week theme (e.g., Week 3 Classroom → "What's in your bag?")

**Examples by Week Theme**:
```javascript
// Week 5 (Daily Routines)
starter_prompts: [
  { text_en: "Let's play Word Chain! 🎮", text_vi: "Chơi nối từ đi cô!", type: "game" },
  { text_en: "How do you say 'đánh răng'? 🦷", text_vi: "Đánh răng tiếng Anh là gì?", type: "help" },
  { text_en: "I wake up at 7 AM! ⏰", text_vi: "Con dậy lúc 7 giờ!", type: "chat" },
  { text_en: "I brush my teeth every day! 😁", text_vi: "Con đánh răng mỗi ngày!", type: "chat" }
]

// Week 10 (Animals)
starter_prompts: [
  { text_en: "Let's play 20 Questions! 🎯", text_vi: "Chơi đoán vật đi cô!", type: "game" },
  { text_en: "How do you say 'con gấu'? 🐻", text_vi: "Con gấu tiếng Anh là gì?", type: "help" },
  { text_en: "I love dogs! 🐶", text_vi: "Con thích chó lắm!", type: "chat" },
  { text_en: "I have a pet cat! 🐱", text_vi: "Con có nuôi mèo!", type: "chat" }
]
```

## 🔒 LOCKED RULES (NON-NEGOTIABLE)

### 1. Variable Naming:
```javascript
// ✅ CORRECT
export const week04RealData = { ... };

// ❌ WRONG
export default { ... };  // NO default export
const weekData = { ... };  // WRONG variable name
```

### 2. Target Vocab Format:
```javascript
// ✅ CORRECT
target_vocab: [
  { 
    word: "happy", 
    pronunciation: "/ˈhæpi/",
    definition_vi: "Vui vẻ", 
    definition_en: "Feeling joy",
    example: "I am happy today.",
    syllabus_context: "Emotions"
  }

target_vocab: ["happy", "sad", "angry"]  // NO strings!
```

```javascript
freetalk_knowledge: { ... }  // NO underscore

free_talk_knowledge: { ... }  // Wrong underscore
```

```javascript
// ✅ CORRECT
free_talk_knowledge: { ... }  // WITH underscore

// ❌ WRONG

```

## 📝 GENERATION WORKFLOW

### Step 1: Read Context
1. Read SPEC file: `MASS/SPECS/week_{{PAD_WEEK}}_spec.json`
2. Extract: topic, grammar, target_vocab
3. Determine week range: Week 1-3 (Basic) or Week 4+ (Variant)

### Step 2: Read Schema
1. **If Week 1-3**: Read `MASS/PROMPTS/05_AI_TUTOR_SCHEMA_BASIC.txt`
2. **If Week 4+**: Read `MASS/PROMPTS/06_AI_TUTOR_SCHEMA_VARIANT.txt`

### Step 3: Generate Missions
1. Mission 1: Introduction (basic vocab)
2. Mission 2: Practice (sentences)
3. Mission 3: Challenge (conversation)

**Week 1-3**:
- Free conversation format
- conversation_topics: 8-10 topics
- example_questions: 5-7 questions
- minimum_turns: 15, maximum_turns: 20

**Week 4+**:
- 9 regular objectives (question_variants)
- 2 student_question invitations
- 1 goodbye objective
- minimum_turns: 27, maximum_turns: 40

### Step 4: Generate FreeTalk
1. knowledge_base: 10-15 facts about topic
2. example_opening_questions: 8-10 questions
3. starter_prompts (Week 4+ only): 5-7 emoji prompts

### Step 5: Validate
1. Check field names (free_talk vs freetalk)
2. Check target_vocab format (objects, not strings)
3. Check export format (export const, not default)
4. Check file structure matches schema

## ⚠️ COMMON MISTAKES

### ❌ Mistake 1: Wrong Field Name
```javascript
// Week 4+ file
free_talk_knowledge: { ... }  // ❌ Has underscore

// Should be:
freetalk_knowledge: { ... }  // ✅ No underscore
```

### ❌ Mistake 2: Target Vocab as Strings
```javascript
target_vocab: ["happy", "sad"]  // ❌ WRONG

// Should be:
target_vocab: [
  { word: "happy", pronunciation: "...", definition_vi: "...", definition_en: "...", example: "...", syllabus_context: "..." }
]  // ✅ Objects
```

### ❌ Mistake 3: Wrong Export
```javascript
export default { ... };  // ❌ WRONG

// Should be:
export const week04RealData = { ... };  // ✅ Named export
```

### ❌ Mistake 4: Missing Student Questions (Week 4+)
```javascript
objectives: [
  { stepKey: "objective_1", ... },
  { stepKey: "objective_2", ... },
  // ... no student_question invitations ❌
  { stepKey: "goodbye", ... }
]

// Should be:
objectives: [
  { stepKey: "objective_1", ... },
  { stepKey: "objective_2", ... },
  { stepKey: "student_question_1", type: "invitation", ... },  // ✅
  { stepKey: "objective_3", ... },
  { stepKey: "student_question_2", type: "invitation", ... },  // ✅
  { stepKey: "goodbye", ... }
]
```

### ❌ Mistake 5: Missing Goodbye (Week 4+)
```javascript
objectives: [
  { stepKey: "objective_1", ... },
  // ... more objectives
  // NO goodbye ❌
]

// Should be:
objectives: [
  { stepKey: "objective_1", ... },
  // ... more objectives
  { stepKey: "goodbye", category: "Closing", ... }  // ✅
]
```
