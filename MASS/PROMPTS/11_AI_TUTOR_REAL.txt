## 📋 SCHEMA SELECTION

### Week 1-3: Basic Schema (Prompt 05)
- Free conversation format
- No objectives array
- default_hints at mission level
- conversation_topics + example_questions
- Field: `free_talk_knowledge` (with underscore)

### Week 4+: Variant Schema (Prompt 06)
- Objective-based structure
- question_variants (3 per objective)
- hints per question (6-9 scrambled words)
- 2 student_question invitations
- goodbye objective
- Field: `freetalk_knowledge` (NO underscore)

**⚠️ CRITICAL**: Read Prompt 05 (Week 1-3) OR Prompt 06 (Week 4+) for complete schema!

## 🎯 FREE TALK 2.0 UPGRADE - FIXED BUTTONS (ALL WEEKS)

### New Field: starter_prompts (Required)

**Purpose**: Provide 4 FIXED UI buttons that work across ALL weeks:
1. **🎮 Games Mode**: Word Chain, I Spy, Emoji Mixer (with sub-menu)
2. **📖 Helper Mode**: Translation/dictionary
3. **🎭 Roleplay Mode**: Pizza Chef, Pet Doctor, Toy Shop (with sub-menu)
4. **❓ Ask Anything Mode**: Free inquiry (age-appropriate knowledge)

**Format**:
```javascript
freetalk_knowledge: {  // or free_talk_knowledge for Week 1-3
  theme: "...",
  knowledge_base: [...],
  example_opening_questions: [...],
  
  // ✅ NEW FIELD (Required for ALL weeks - FIXED ACROSS ALL WEEKS)
  starter_prompts: [
    { text_en: "I want to play games! 🎮", text_vi: "Tôi muốn chơi game!", type: "game" },
    { text_en: "Translate this for me... 📖", text_vi: "Dịch giúp con câu/chữ này...", type: "help" },
    { text_en: "Let's do roleplay! 🎭", text_vi: "Chơi nhập vai đi cô!", type: "roleplay" },
    { text_en: "I have a question! ❓", text_vi: "Con có câu hỏi!", type: "ask_anything" }
  ]
}
```

**Rules**:
- **Count**: Exactly 4 prompts per week
- **Distribution**: 1 game + 1 help + 1 roleplay + 1 ask_anything
- **text_en**: FIXED ENGLISH TEXT (same for all weeks)
- **text_vi**: FIXED VIETNAMESE TEXT (same for all weeks)
- **type**: Must be "game", "help", "roleplay", or "ask_anything"
- **NO CUSTOMIZATION**: Use the EXACT text above for ALL weeks (Week 4-156)

**CRITICAL - These Are Entry Points (Not Specific Actions)**:
- ✅ "I want to play games!" → AI shows sub-menu: Word Chain, I Spy, Emoji Mixer
- ✅ "Translate this for me..." → AI asks: "What word do you want to translate?"
- ✅ "Let's do roleplay!" → AI shows sub-menu: Pizza Chef, Pet Doctor, Toy Shop
- ✅ "I have a question!" → AI asks: "What do you want to know?"

**AI Behavior After Button Click**:
1. **Games Mode**: Show menu → "What games do you like to play?" + hints: ["Word Chain", "I Spy", "Emoji Mixer"]
2. **Helper Mode**: Ask for word → "What do you want to translate?"
3. **Roleplay Mode**: Show menu → "Which character do you want to be?" + hints: ["The Pizza Chef", "The Pet Doctor", "The Toy Shop"]
4. **Ask Anything Mode**: Wait for question → "What do you want to know?"

**Game Rules (After Student Chooses)**:
- **Word Chain**: AI starts "Dog 🐶 (ends with G)" → Student continues
- **I Spy**: AI describes "It is green. It jumps. Ribbit!" → Student guesses
- **Emoji Mixer**: AI shows "🌞 + 👓 = ?" → Student guesses "Sunglasses"

**Roleplay Scenarios (After Student Chooses)**:
- **Pizza Chef**: Student = Chef, AI = Customer ordering food
- **Pet Doctor**: Student = Doctor, AI has sick pet
- **Toy Shop**: Student = Shop Owner, AI = Customer buying toys

```javascript
// ✅ CORRECT
target_vocab: [
```

## 📝 GENERATION WORKFLOW

### Step 1: Read Context
1. Read SPEC file: `MASS/SPECS/week_{{PAD_WEEK}}_spec.json`
2. Extract: topic, grammar, target_vocab
3. Determine week range: Week 1-3 (Basic) or Week 4+ (Variant)

### Step 2: Read Schema
1. **If Week 1-3**: Read `MASS/PROMPTS/05_AI_TUTOR_SCHEMA_BASIC.txt`
2. **If Week 4+**: Read `MASS/PROMPTS/06_AI_TUTOR_SCHEMA_VARIANT.txt`

### Step 3: Generate Missions
1. Mission 1: Introduction (basic vocab)
2. Mission 2: Practice (sentences)
3. Mission 3: Challenge (conversation)

**Week 1-3**:
- Free conversation format
- conversation_topics: 8-10 topics
- example_questions: 5-7 questions
- minimum_turns: 15, maximum_turns: 20

**Week 4+**:
- 9 regular objectives (question_variants)
- 2 student_question invitations
- 1 goodbye objective
- minimum_turns: 27, maximum_turns: 40

### Step 4: Generate FreeTalk
1. knowledge_base: 10-15 facts about topic
2. example_opening_questions: 8-10 questions
3. starter_prompts (Week 4+ only): 5-7 emoji prompts

### Step 5: Validate
1. Check field names (free_talk vs freetalk)
2. Check target_vocab format (objects, not strings)
3. Check export format (export const, not default)
4. Check file structure matches schema

## ⚠️ COMMON MISTAKES

### ❌ Mistake 1: Wrong Field Name
```javascript
// Week 4+ file
free_talk_knowledge: { ... }  // ❌ Has underscore

// Should be:
freetalk_knowledge: { ... }  // ✅ No underscore
```

### ❌ Mistake 2: Target Vocab as Strings
```javascript
target_vocab: ["happy", "sad"]  // ❌ WRONG

// Should be:
target_vocab: [
  { word: "happy", pronunciation: "...", definition_vi: "...", definition_en: "...", example: "...", syllabus_context: "..." }
]  // ✅ Objects
```

### ❌ Mistake 3: Wrong Export
```javascript
export default { ... };  // ❌ WRONG

// Should be:
export const week04RealData = { ... };  // ✅ Named export
```

### ❌ Mistake 4: Missing Student Questions (Week 4+)
```javascript
objectives: [
  { stepKey: "objective_1", ... },
  { stepKey: "objective_2", ... },
  // ... no student_question invitations ❌
  { stepKey: "goodbye", ... }
]

// Should be:
objectives: [
  { stepKey: "objective_1", ... },
  { stepKey: "objective_2", ... },
  { stepKey: "student_question_1", type: "invitation", ... },  // ✅
  { stepKey: "objective_3", ... },
  { stepKey: "student_question_2", type: "invitation", ... },  // ✅
  { stepKey: "goodbye", ... }
]
```

### ❌ Mistake 5: Missing Goodbye (Week 4+)
```javascript
objectives: [
  { stepKey: "objective_1", ... },
  // ... more objectives
  // NO goodbye ❌
]

// Should be:
objectives: [
  { stepKey: "objective_1", ... },
  // ... more objectives
  { stepKey: "goodbye", category: "Closing", ... }  // ✅
]
```
