## 🔑 CRITICAL CONCEPTS

### 1. TARGET_VOCAB: Objects, NOT Strings!

**❌ WRONG**:
```javascript
target_vocab: ["happy", "sad", "funny"]  // Strings - will break Quiz/Speak tabs!
```

**✅ CORRECT**:
```javascript
target_vocab: [
  {
    word: "happy",
    pronunciation: "/ˈhæpi/",
    definition_vi: "vui vẻ",
    definition_en: "feeling very good and joyful",
    example: "I am happy today.",
    syllabus_context: "Emotions"
  },
  // 7-10 word objects
]
```

**Why?** Quiz and Speak tabs expect objects with `word`, `pronunciation`, `definition_vi`, etc.

### 2. Mission Title Keywords (for TurnManager Detection)

TurnManager.js uses mission title keywords to detect which week is active:

**Week detection logic**:
```javascript
// In TurnManager.js
if (title.includes("Family") || title.includes("Mother") || title.includes("Father")) {
  // Week 2 logic
} else if (title.includes("Mirror") || title.includes("Appearance")) {
  // Week 3 logic
} else if (title.includes("Happy") || title.includes("Emotions")) {
  // Week 4 logic
} else {
  // Week 1 default logic
}
```

**CRITICAL**: Mission titles MUST include distinctive keywords!

**Examples**:
- Week 1: "Mission 1: Meeting at School" (default)
- Week 2: "Mission 1: My Family Album" (keyword: Family)
- Week 3: "Mission 1: Mirror, Mirror on the Wall" (keyword: Mirror)
- Week 4: "Mission 1: My Happy Jar" (keyword: Happy)

### 3. Objective Structure Differences

**Week 1-3 (canonical_question)**:
```javascript
{
  stepKey: "student_name",
  category: "Identity",
  canonical_question: "What is your name?",  // Single question
  hints: ["name", "is", "My"],  // Individual words
  target_keywords: ["my", "name", "is"],
  ack_options: ["Nice!", "Great!"],
  recast_templates: ["Your name is {name}!"],
  success_criteria: "Student says their name"
}
```

**Week 4+ (question_variants)**:
```javascript
{
  stepKey: "student_name",
  category: "Identity",
  question_variants: [  // 3 variants for replay
    {
      question: "What is your name?",
      hints: ["name", "is", "My", "I", "am"]  // Full scrambled sentence
    },
    {
      question: "Can you tell me your name?",
      hints: ["is", "My", "name", "tell", "you", "I"]
    },
    {
      question: "What do I call you?",
      hints: ["call", "me", "You", "can", "My", "name"]
    }
  ],
  target_keywords: ["my", "name", "is", "I", "am"],
  ack_options: ["Nice!", "Great!"],
  recast_templates: ["Your name is {name}!"],
  success_criteria: "Student says their name"
}
```

**Key differences**:
- canonical_question: 1 question, 3-5 word hints
- question_variants: 3 questions, 6-9 word hints (full sentence)

### 4. Student Question Invitations (Week 4+ Only)

Every mission should have **2 student question invitations**:

```javascript
{
  stepKey: "student_question_1",
  category: "Student Inquiry",
  type: "invitation",  // CRITICAL field
  question_variants: [
    {
      question: "Do you have any questions for me?",
      hints: []  // Empty hints - open-ended
    },
    {
      question: "Is there anything you want to ask?",
      hints: []
    },
    {
      question: "What would you like to know?",
      hints: []
    }
  ],
  target_keywords: [],
  ack_options: ["Good question!", "That's interesting!"],
  recast_templates: [],
  allow_skip: true,  // Student can skip
  success_criteria: "Student asks a question or skips"
}
```

**Placement**: Insert after every 3-4 regular objectives

**Purpose**: Encourages student-initiated questions, making conversation more natural

### 5. Goodbye Objective (All Weeks)

Every mission ends with goodbye:

```javascript
{
  stepKey: "goodbye",
  category: "Closing",
  question_variants: [  // or canonical_question for Week 1-3
    {
      question: "How do you say goodbye?",
      hints: ["Goodbye", "See", "you", "Bye"]
    },
    {
      question: "Time to go! What do you say?",
      hints: ["Bye", "Goodbye", "See", "later"]
    },
    {
      question: "Let's end our chat. Say goodbye!",
      hints: ["Goodbye", "Bye", "you", "See"]
    }
  ],
  target_keywords: ["goodbye", "bye", "see you"],
  ack_options: ["Bye!", "See you next time!", "Goodbye!"],
  recast_templates: [],
  success_criteria: "Student says goodbye"
}
```

## 🔧 TROUBLESHOOTING

### Problem 1: target_vocab is array of strings
**Symptom**: Quiz tab shows undefined, Speak tab doesn't work
**Solution**: Convert to array of objects with all 6 fields

### Problem 2: TurnManager doesn't detect week
**Symptom**: Conversation uses Week 1 logic for all weeks
**Solution**: Add distinctive keywords to mission titles

### Problem 3: Week 4+ missing question_variants
**Symptom**: Objectives show undefined question
**Solution**: Replace canonical_question with question_variants array

### Problem 4: Hints not scrambled
**Symptom**: Hints appear in sentence order
**Solution**: For question_variants, hints should be 6-9 words in random order

### Problem 5: Missing student invitations
**Symptom**: Conversation feels one-sided
**Solution**: Add 2 student_question objectives per mission with `type: "invitation"`
