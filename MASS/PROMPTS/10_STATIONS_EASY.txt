## 🎯 OVERVIEW

This file contains **complete schemas** for all 14 Easy station files.

**Difficulty level**: Easy
- Shorter passages (50-80 words vs 150-200)
- Simpler grammar structures
- 60% simplified vocabulary
- More multiple choice, less open-ended

**File structure**: IDENTICAL to Advanced, but simplified content

---

## KEY DIFFERENCES: EASY vs ADVANCED

### Reading Passages:
- **Advanced**: 150-200 words, 10-14 sentences
- **Easy**: 50-80 words, 6-8 sentences

### Vocabulary:
- **Advanced**: Full target vocab (100%)
- **Easy**: Simplified vocab (60% easier words)
  - Example: "excited" → "happy", "adventure" → "trip"

### Grammar:
- **Advanced**: Complex structures for CEFR level
- **Easy**: One level below CEFR
  - Week 4 (A0): Use pre-A0 structures
  - Week 20 (A0+): Use A0 structures

### Questions:
- **Advanced**: Open-ended, analytical
- **Easy**: Multiple choice, simpler answers

### Writing:
- **Advanced**: 40+ words minimum
- **Easy**: 20-30 words minimum

## 2. READ.JS (~40 lines)

**MAJOR simplification**:
- **50-80 words** (vs 150-200)
- **6-8 sentences** (vs 10-14)
- Simpler plot
- Present simple tense focus

```javascript
export default {
  title: "My Happy Day",  // Simpler title
  image_url: "/images/weekX/read_cover_wXX.jpg",  // Same
  
  content_en: "I am Sam. I am **happy** today. I **play** with my dog. I **read** my book. I **draw** pictures. I like my day. My day is good!",
  // 50-80 words
  // Same vocab words but simpler sentences
  // 3-5 words per sentence
  
  content_vi: "Tôi là Sam. Hôm nay tôi vui. Tôi chơi với chó của tôi...",
  
  check_questions: [
    {
      id: 1,
      question_en: "Who is happy?",  // SIMPLER question
      answer: ["Sam"],
      hint_en: "Look at the first sentence...",
      hint_vi: "Nhìn vào câu đầu tiên..."
    },
    {
      id: 2,
      question_en: "What does Sam do?",  // SIMPLER
      answer: ["play", "read", "draw", "plays", "reads", "draws"],  // More answers accepted
      hint_en: "He does many things...",
      hint_vi: "Anh ấy làm nhiều thứ..."
    },
    {
      id: 3,
      question_en: "Is Sam happy?",  // Yes/No question
      answer: ["yes", "yes he is"],
      hint_en: "Look at the title...",
      hint_vi: "Nhìn vào tiêu đề..."
    }
  ],
  
  question: {
    text_en: "What do you do when you are happy?",  // SIMPLER prompt
    text_vi: "Bạn làm gì khi bạn vui?",
    min_words: 20,  // Lower (was 30)
    hint_en: "Tell us 2-3 things you like to do...",
    hint_vi: "Kể cho chúng tôi 2-3 điều bạn thích làm..."
  }
};
```

**Simplification rules**:
- Sentences: 3-5 words each
- No complex clauses (when, because, if)
- Present simple tense primarily
- Linear storyline (no flashbacks)
- check_questions: More concrete, less analytical
- More yes/no questions

```javascript
      },

        type: "rule",
        icon: "2️⃣",
        rule_en: "I don't like + V-ing",
        rule_vi: "I don't like + V-ing"

    ]
  },
  
  exercises: [
    // 30% AFFIRMATIVE (6 exercises)
    {
      id: 1,
      type: "mc",  // MORE multiple choice for Easy
      question: "I like _____ games.",
      options: ["play", "playing", "plays"],
      answer: "playing",
      hint: "like + playing"
    },
    {
      id: 2,
      type: "mc",
      question: "She likes _____ books.",
      options: ["read", "reading", "reads"],
      answer: "reading",
      hint: "like + reading"
    },
    // LESS fill-in-the-blank, MORE multiple choice
    
    // 30% NEGATIVE (6 exercises)
    {
      id: 7,
      type: "mc",
      question: "I _____ like running.",
      options: ["do", "don't", "doesn't"],
      answer: "don't",
      hint: "I + don't"
    },
    
    // 40% QUESTIONS (8 exercises)

      id: 13,
      type: "mc",

```

**Simplification rules**:
- 60% multiple choice (vs 40% in Advanced)
- 20% fill-in-blank (vs 30% in Advanced)
- 20% unscramble (vs 30% in Advanced)
- Clearer hints
- Shorter sentences in questions

## 8. LOGIC.JS (~50 lines)

**SIMPLER puzzles**:
- Direct matching only
- No complex deduction

```javascript
export default {
  puzzles: [
    {
      id: 1,
      question_en: "Sam likes reading. Who likes reading?",  // VERY simple
      question_vi: "Sam thích đọc. Ai thích đọc?",
      answer: ["Sam"],
      hint_en: "Look for Sam...",
      hint_vi: "Tìm Sam...",
      audio_url: "/audio/weekX/logic_1.mp3"
    },
    {
      id: 2,
      question_en: "Mia is happy. Happy people smile. Does Mia smile?",  // Simple if-then
      question_vi: "Mia vui. Người vui thì cười. Mia có cười không?",
      answer: ["yes", "yes she does"],
      hint_en: "Happy people...",
      hint_vi: "Người vui thì...",
      audio_url: "/audio/weekX/logic_2.mp3"
    },
    // 5 puzzles
    // NO comparatives, NO complex chains
  ]
};
```

**Puzzle types for Easy**:
- ✅ Direct matching (Who likes X?)
- ✅ Simple if-then (If X, then Y. X is true. Is Y true?)
- ❌ NO comparatives (more than, less than)
- ❌ NO multi-step deductions

## ✅ EASY vs ADVANCED SUMMARY

| Feature | Advanced | Easy |
|---------|----------|------|
| **read.js** | 150-200 words, 10-14 sentences | 50-80 words, 6-8 sentences |
| **Writing min_words** | 40+ | 20-30 |
| **Grammar exercises** | 40% MC, 30% fill, 30% unscramble | 60% MC, 20% fill, 20% unscramble |

## 🚨 CRITICAL RULES FOR EASY

1. **Always one CEFR level below** Advanced
2. **60% multiple choice** in grammar exercises
3. **More yes/no questions** in comprehension
4. **Shorter sentences**: 3-5 words average
5. **Simpler vocabulary**: Replace complex words with basic ones
6. **Lower word counts**: read (50-80), writing (20-30), explore (80-100)
