## 🎯 VALIDATION PHILOSOPHY

**Goal**: Ensure generated content is:
- Syntactically correct (no JS errors)
- Semantically correct (follows schemas)
- Cross-referenced correctly (stations match AI Tutor)
- Functionally correct (loads and runs in app)

**Validation Levels**:
1. **Syntax**: File structure and JS validity
2. **Schema**: Follows prompt specifications
3. **Cross-Reference**: Inter-file dependencies
4. **Functional**: Works in running app

## LEVEL 3: CROSS-REFERENCE VALIDATION

### 3.1 vocab.js → read.js (Bolded Words)
```bash
# Extract bolded words from read.js
grep -o '\*\*[^*]*\*\*' src/data/weeks/week_XX/read.js | sed 's/\*\*//g' | sort -u > /tmp/bolded.txt

# Extract words from vocab.js
node -e "const v = require('./src/data/weeks/week_XX/vocab.js').default; v.vocab.forEach(w => console.log(w.word))" > /tmp/vocab.txt

# Compare
echo "Bolded words in read.js:"
cat /tmp/bolded.txt
echo "Vocab words:"
cat /tmp/vocab.txt
echo "Coverage: Should have at least 50% of vocab words bolded"
```

**Rule**: At least 5 out of 10 vocab words should be bolded in read.js

### 3.2 read.js → dictation.js (Sentence Match)
```bash
# Count sentences in read.js
SENTENCES=$(echo "$READ_CONTENT" | tr '.' '\n' | grep -v '^$' | wc -l)

# Count dictation exercises
DICTATION_COUNT=$(node -e "const d = require('./src/data/weeks/week_XX/dictation.js').default; console.log(d.sentences.length)")

echo "Read sentences: $SENTENCES"
echo "Dictation sentences: $DICTATION_COUNT"
echo "Match: $([ $SENTENCES -eq $DICTATION_COUNT ] && echo '✓' || echo '✗ COUNT MISMATCH')"
```

**Rule**: dictation.js sentence count MUST equal read.js sentence count

### 3.3 dictation.js → shadowing.js (Sentence Match)
```bash
node -e "
const d = require('./src/data/weeks/week_XX/dictation.js').default;
const s = require('./src/data/weeks/week_XX/shadowing.js').default;
console.log('Dictation count:', d.sentences.length);
console.log('Shadowing count:', s.sentences.length);
console.log('Match:', d.sentences.length === s.sentences.length ? '✓' : '✗');
console.log('First sentence match:', d.sentences[0].text === s.sentences[0].text ? '✓' : '✗');
"
```

**Rule**: shadowing.js MUST have same sentences as dictation.js (+ audio_url)

### 3.4 vocab.js → writing.js (Keywords)
```bash
node -e "
const v = require('./src/data/weeks/week_XX/vocab.js').default;
const w = require('./src/data/weeks/week_XX/writing.js').default;
const vocabWords = v.vocab.map(x => x.word);
const keywords = w.keywords;
const overlap = keywords.filter(k => vocabWords.includes(k));
console.log('Writing keywords:', keywords.length);
console.log('From vocab:', overlap.length, '(' + Math.round(overlap.length/keywords.length*100) + '%)');
console.log('Rule: At least 50% keywords should be from vocab');
"
```

**Rule**: At least 50% of writing.js keywords should be from vocab.js

### 3.5 vocab.js → word_match.js (Complete Match)
```bash
node -e "
const v = require('./src/data/weeks/week_XX/vocab.js').default;
const wm = require('./src/data/weeks/week_XX/word_match.js').default;
console.log('Vocab words:', v.vocab.length);
console.log('Word match pairs:', wm.pairs.length);
console.log('Match:', v.vocab.length === wm.pairs.length ? '✓' : '✗ MUST BE 10');
"
```

**Rule**: word_match.js MUST have exactly 10 pairs (all vocab words)

### 3.6 daily_watch.js → video_queries.json (Video Match)
```bash
node -e "
const dw = require('./src/data/weeks/week_XX/daily_watch.js').default;
```
