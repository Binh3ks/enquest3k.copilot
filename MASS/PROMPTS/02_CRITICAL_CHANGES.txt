## 🔥 WEEK 1-3 vs WEEK 4+ SCHEMA PATTERNS

### Pattern 1: Simple Questions (Week 1-3)

**When to use**: Week 1-3, introductory weeks, first-time focus

**Schema**:
```javascript
objectives: [
  {
    stepKey: "greeting",
    category: "Introduction",
    canonical_question: "Hello! What is your name?",  // ONE question
    hints: ["My", "name", "is", "I", "am"],  // 5-6 individual words
    target_keywords: ["name", "my", "is"],
    ack_options: ["Nice!", "Great!", "Wonderful!"],  // 3 only
    recast_templates: ["Your name is {name}!", "You are {name}!"],
    success_criteria: "Student provides name"
  }
]
```

**Key features**:
- `canonical_question`: Single question string
- `hints`: 5-6 individual words (not full sentence)
- `minimum_turns`: 10 (Mission 1-2), 8 (Mission 3)
- NO `question_variants`
- NO `student_question_invitation`

---

### Pattern 2: Question Variants (Week 4+)

**When to use**: Week 4+, replay value, student engagement

**Schema**:
```javascript
objectives: [
  {
    stepKey: "what_like_doing",
    category: "Interests",
    question_variants: [  // 🔥 3 variants instead of single question
      {
        question: "What do you like doing?",
        hints: ["like", "I", "playing", "reading", "and", "drawing"]  // 6-9 words, scrambled
      },
      {
        question: "What is your favorite activity?",
        hints: ["favorite", "my", "is", "playing", "reading", "games"]  // Different scramble
      },
      {
        question: "What do you enjoy the most?",
        hints: ["enjoy", "I", "the", "most", "playing", "reading", "drawing"]  // Different again
      }
    ],
    target_keywords: ["like", "love", "playing", "reading"],
    ack_options: ["Nice!", "Great!", "Wonderful!"],
    recast_templates: ["You like {activity}!", "You enjoy {activity}!"],
    success_criteria: "Student shares activity"
  },
  
  // 🔥 Student question invitation (every 3-4 objectives)
  {
    stepKey: "student_question_1",
    category: "Student Inquiry",
    type: "invitation",  // Special type for TurnManager
    question_variants: [
      { question: "Ask me anything!", hints: [] },
      { question: "You can ask me a question now!", hints: [] },
      { question: "Do you have a question for me?", hints: [] }
    ],
    target_keywords: ["question", "ask", "what", "how", "why", "yes", "no"],
    ack_options: ["Great question!", "Good question!"],
    recast_templates: ["You asked about {topic}!"],
    success_criteria: "Student asks a question OR declines",
    allow_skip: true  // Student can say "no"
  }
]
```

**Key features**:
- `question_variants`: 3 variants per objective
- `hints`: 6-9 words forming full scrambled sentence
- `minimum_turns`: 15 (Mission 1-2), 12 (Mission 3)
- `student_question_invitation`: 1-2 per mission
- `type: "invitation"`: Special type for invitations

## 🔥 CRITICAL: target_vocab MUST BE OBJECTS

### ❌ WRONG (Breaks Quiz & Speak tabs):
```javascript
target_vocab: ["happy", "sad", "excited", "funny", "friendly"]  // Just strings
```

**Why this fails**:
- Quiz tab needs `definition_vi` for questions → Shows "undefined"
- Speak tab needs `pronunciation` for IPA display → Shows "undefined"
- Vocab station needs `example` for sentences → Shows "undefined"

### ✅ CORRECT (Week 2, 3, 4 format):
```javascript
target_vocab: [
  {
    word: "happy",
    pronunciation: "/ˈhæpi/",
    definition_vi: "vui vẻ",
    definition_en: "feeling very good and joyful",
    example: "I am happy today.",
    syllabus_context: "Emotions"
  },
  {
    word: "sad",
    pronunciation: "/sæd/",
    definition_vi: "buồn",
    definition_en: "feeling unhappy",
    example: "I am sad when it rains.",
    syllabus_context: "Emotions"
  }
  // ... 8-10 total words
]
```

**Required fields**:
- `word`: The vocabulary word
- `pronunciation`: IPA format
- `definition_vi`: Vietnamese translation
- `definition_en`: English definition (max 10 words, A0 level)
- `example`: Simple sentence using the word
- `syllabus_context`: Theme/topic

## 🔥 RECENT BUG FIXES (Week 4 - Jan 16-17, 2026)

### Bug 1: Logic Lab Format Error
**Symptom**: Logic Lab station shows "undefined" or blank

**Root Cause**: Component reads `data.puzzles`, but file exported `problems:`

**Fix**:
```javascript
// ❌ WRONG:
export default {
  problems: [...]  // Component can't find this
};

// ✅ CORRECT:
export default {
  puzzles: [...]  // Component reads data.puzzles
};
```

**Prevention**: Always use `puzzles:` in logic.js

---

### Bug 2: Video Queries JSON Key Error
**Symptom**: `update_videos.js` script fails with "Cannot read property 'map' of undefined"

**Root Cause**: Script expects `data.videos`, but JSON has `"video_queries": [...]`

**Fix**:
```json
// ❌ WRONG:
{
  "weekId": 4,
  "video_queries": [...]
}

// ✅ CORRECT:
{
  "weekId": 4,
  "videos": [...]
}
```

**Prevention**: Always use `"videos": [...]` in video_queries.json

---

### Bug 3: Missing Daily Watch Registration
**Symptom**: Daily Watch station shows blank/white screen despite file existing

**Root Cause**: `DailyWatch.jsx` receives `null` data prop because not registered in index.js

**Fix**:
```javascript
// ❌ WRONG (missing import):
import read from './read.js';
import vocab from './vocab.js';
// ... other imports ...
// ⛔ MISSING: import daily_watch from './daily_watch.js';

const weekData = {
  stations: {
    read_explore: read,
    new_words: vocab,
    // ⛔ MISSING: daily_watch: daily_watch
  }
};

// ✅ CORRECT:
import read from './read.js';
import vocab from './vocab.js';
import daily_watch from './daily_watch.js';  // ✅ MUST IMPORT

const weekData = {
  stations: {
    read_explore: read,
    new_words: vocab,
    daily_watch: daily_watch  // ✅ MUST REGISTER
  }
};
```

**Prevention**: Always import and register `daily_watch` in index.js

## 🔥 V28 FORMAT CHANGES (ACK/RECAST/QUESTION)

### OLD Format (V27) - DO NOT USE:
```json
{
  "teacher_ack": "Great!",
  "teacher_recast": "Your name is Binh!",
  "teacher_question": "How old are you?",
  "suggested_hints": ["I", "am", "years", "old"],
  "mission_status": "continue"
}
```

### NEW Format (V28) - USE THIS:
```json
{
  "ack": "Nice!",
  "recast": "Your name is Binh!",
  "question": "How old are you?",
  "suggested_hints": ["I", "am", "years", "old"],
  "mission_status": "continue"
}
```

**Changes**:
- `teacher_ack` → `ack` (simpler)
- `teacher_recast` → `recast` (remove "teacher_" prefix)
- `teacher_question` → `question` (clearer)

## 🔥 ACK REDUCTION (6 → 3 Options)

### OLD (V27) - TOO MANY:
- Great! Perfect! Nice! Wonderful! Excellent! Good!

### NEW (V28) - 3 ONLY:
- **Nice!** (warm, friendly)
- **Great!** (encouraging)
- **Wonderful!** (enthusiastic)

**Why**: More variety = less authentic teacher response. Real teachers use 2-3 favorites consistently.

## 🔥 SUBJECT AGREEMENT (RECAST Technique)

### Problem: AI uses wrong subject in RECAST

**Example - Talking about MOTHER**:
```
Question: "What does your mother do?"
Student: "cook"
❌ WRONG RECAST: "You cook!" ← Wrong subject!
✅ CORRECT RECAST: "She cooks!" ← Correct subject
```

### Solution: RECAST must match question subject

| Question Subject | Correct RECAST Subject |
|------------------|------------------------|
| "your mother" / "mom" | **She** or **Your mother** |
| "your father" / "dad" | **He** or **Your father** |
| "you" / "your name" | **You** |
| "they" / "children" | **They** |

**Examples**:
```
Q: "Is your mother busy?"
Student: "yes"
✅ RECAST: "She is busy!" (NOT "You are busy!")

Q: "What does your father do?"
Student: "works"
✅ RECAST: "He works!" (NOT "You work!")

Q: "Are you a student?"
Student: "yes"
✅ RECAST: "You are a student!" (Correct)
```
