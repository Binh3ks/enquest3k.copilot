### Critical Audio Rules:

#### 1. Remove Markdown Before TTS

**Why**: TTS reads asterisks and underscores out loud

**What to remove**:
- `**bold**` markers: "My **name** is" → "My name is"
- `___` blanks: "This is my ___." → "This is my."

**When**: Before TTS generation (script does this automatically)

**Not in source data**: Keep markdown in .js files, clean only for TTS

#### 2. File Naming Convention

| Station | File Name Format | Example | Notes |
|---------|------------------|---------|-------|
| **Read** | `read_explore_main.mp3` | `/audio/week4/read_explore_main.mp3` | NOT `read_main.mp3` |
| **Explore** | `explore_main.mp3` | `/audio/week4/explore_main.mp3` | NOT `explore_explore_main.mp3` |

### 5. Mindmap Audio Auto-Fill

**Problem**: Mindmap data starts as strings, needs audio URLs

**Solution**: Run auto-fill script AFTER audio generation

**Command**:
```bash
node tools/update_mindmap_audio_urls.js <week_number>

# Example for Week 4:
node tools/update_mindmap_audio_urls.js 4
```

**What it does**:
```javascript
// BEFORE (strings only):
centerStems: ["This is my ___.", "I feel ___."]
branchLabels: {
  "This is my ___.": ["mother and father", "big brother"]
}

// AFTER (objects with audio URLs):
centerStems: [
  { text: "This is my ___.", audio: "/audio/week4/mindmap_stem_1.mp3" },
  { text: "I feel ___.", audio: "/audio/week4/mindmap_stem_2.mp3" }
]
branchLabels: {
  "This is my ___.": [
    { text: "mother and father", audio: "/audio/week4/mindmap_branch_1.mp3" },
    { text: "big brother", audio: "/audio/week4/mindmap_branch_2.mp3" }
  ]
}
```

**When to run**: AFTER audio generation, BEFORE final validation

### 6. Voice Configuration Strategy

**Problem**: Same voices for 3+ weeks = monotonous

**Solution**: Remix voiceConfig every new week

**Available Voices** (Google Cloud Neural2 - US English):

**Female (Clear, Energetic)**:
- `en-US-Neural2-C`: Young adult, warm and clear
- `en-US-Neural2-E`: Adult, professional and friendly
- `en-US-Neural2-F`: Young, soft and gentle
- `en-US-Neural2-G`: Adult, authoritative but warm
- `en-US-Neural2-H`: Young, bright and cheerful

**Male (Clear, Engaging)**:
- `en-US-Neural2-A`: Young adult, energetic and clear
- `en-US-Neural2-D`: Adult, neutral and clear
- `en-US-Neural2-I`: Young, friendly and expressive
- `en-US-Neural2-J`: Adult, warm and trustworthy

**Rotation Strategy**:
1. Check previous 2 weeks' voiceConfig
2. Change at least 3 out of 5 voices
3. Mix male and female voices (not all one gender)
4. Example:

```javascript
// Week 3 (baseline):
voiceConfig: {
  narration: 'en-US-Neural2-D',   // Male
  vocabulary: 'en-US-Neural2-F',  // Female
  dictation: 'en-US-Neural2-F',   // Female
  questions: 'en-US-Neural2-D',   // Male
  mindmap: 'en-US-Neural2-D'      // Male
}

// Week 4 (remix - 4 out of 5 changed):
voiceConfig: {
  narration: 'en-US-Neural2-C',   // ✅ Female (changed)
  vocabulary: 'en-US-Neural2-A',  // ✅ Male (changed)
  dictation: 'en-US-Neural2-I',   // ✅ Male (changed)
  questions: 'en-US-Neural2-E',   // ✅ Female (changed)
  mindmap: 'en-US-Neural2-C'      // Female (matches narration)
}

// Week 5 (different again - 3 out of 5 changed from Week 4):
voiceConfig: {
  narration: 'en-US-Neural2-A',   // ✅ Male (changed)
  vocabulary: 'en-US-Neural2-H',  // ✅ Female (changed)
  dictation: 'en-US-Neural2-E',   // Female (kept from W4)
  questions: 'en-US-Neural2-J',   // ✅ Male (changed)
  mindmap: 'en-US-Neural2-A'      // Male (matches narration)
}
```

**Rule**: Never use same 5 voices for 3+ consecutive weeks

## 🔍 TROUBLESHOOTING

### Problem: Audio files not generating
**Symptoms**: Script runs but no .mp3 files created

**Causes**:
1. Google Cloud TTS API key expired
2. Insufficient API quota
3. Text too long (>5000 chars per request)

**Solutions**:
1. Check API key in `.env` file
2. Check quota: https://console.cloud.google.com/apis/api/texttospeech.googleapis.com/quotas
3. Split long texts into chunks (script does this automatically)

---

### Problem: Mindmap has no audio (falls back to browser TTS)
**Symptoms**: Mindmap works but voice sounds different

**Cause**: Forgot to run `update_mindmap_audio_urls.js`

**Solution**:
```bash
node tools/update_mindmap_audio_urls.js 4
```

---

### Problem: Cover images not displaying
**Symptoms**: Blank image in Read & Explore or CLIL Explore

**Causes**:
1. Missing `image_url` field in read.js/explore.js
2. Wrong filename (missing `_w04` suffix)
3. Wrong path (using `week_04` instead of `week4`)

**Solutions**:
1. Add `image_url` field
2. Check actual filename in `public/images/week4/` folder
3. Use correct path format: `/images/week4/read_cover_w04.jpg`

---

### Problem: Videos not syncing to Easy mode
**Symptoms**: Advanced has videos, Easy is blank

**Cause**: Forgot to run `update_videos.js`

**Solution**:
```bash
node tools/update_videos.js 4
# Verify: "✅ Synced Easy mode" appears
```
