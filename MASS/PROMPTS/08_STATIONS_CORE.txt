## 🔑 COMMON SCHEMA ELEMENTS (All Stations)

### CEFR Level Mapping:
```javascript
Week 1-18:   CEFR A0  (Super basic)
Week 19-36:  CEFR A0+ (Basic+)
Week 37-54:  CEFR A1  (Elementary)
Week 55-72:  CEFR A1+ (Elementary+)
Week 73-90:  CEFR A2  (Pre-intermediate)
Week 91-108: CEFR A2+ (Pre-intermediate+)
Week 109-156: CEFR B1 (Intermediate)
```

### Grammar Complexity by Level:

**A0 (Week 1-18)**:
- Present simple (I am, I have)
- Basic pronouns (I, you, he, she)
- Simple sentences (3-5 words)

**A0+ (Week 19-36)**:
- Present continuous (I am playing)
- Basic questions (Do you...?)
- Sentences (5-7 words)

**A1 (Week 37-54)**:
- Past simple (I played)
- Can/Can't
- Sentences (7-10 words)

**A1+ (Week 55-72)**:
- Future (will, going to)
- Comparatives (bigger, smaller)
- Sentences (10-12 words)

**A2 (Week 73-90)**:
- Present perfect (I have seen)
- Modal verbs (should, must)
- Sentences (12-15 words)

**A2+ (Week 91-108)**:
- Past continuous (I was playing)
- Conditionals (If I...)
- Sentences (15-18 words)

**B1 (Week 109-156)**:
- Mixed tenses
- Passive voice
- Complex sentences (18-25 words)

### Vocabulary Tiers:

**Advanced mode**: Use 100% target vocab + challenge words
**Easy mode**: Use 60% simplified vocab + basic words

Example:
- Advanced: "I feel **excited** about the **adventure**."
- Easy: "I am **happy** about the **trip**."

### Cross-Reference Rules:

**Rule 1: vocab.js → All stations**
- All stations MUST use words from vocab.js
- vocab.js has 10 words (id 1-10)
- Each word is an object with: word, pronunciation, definition_vi, definition_en, example, collocation, image_url, audio_word

**Rule 2: read.js → dictation.js + shadowing.js**
- dictation.js exercises MUST be sentences from read.js content
- Count sentences in read.js → Create same number of dictation exercises
- shadowing.js MUST use same sentences

**Rule 3: vocab.js → read.js**
- read.js content MUST **bold** vocab words using **word** syntax
- Example: "I am **happy** today." (if "happy" is in vocab.js)

**Rule 4: vocab.js → writing.js**
- writing.js keywords MUST come from vocab.js words
- Choose 3-5 words from vocab list

**Rule 5: Theme consistency**
- All 14 stations MUST use same theme from syllabus_database.js
- Example: Week 4 theme = "Emotions" → All stations about emotions

## ✅ VALIDATION CHECKLIST (Before Finishing)

### Phase 1: Individual File Checks
Run for each file:
```bash
node -e "const f = require('./src/data/weeks/week_XX/vocab.js'); console.log(f)"
```

Check:
- [ ] No syntax errors
- [ ] File exports correctly
- [ ] All required fields present

### Phase 2: Cross-Reference Checks

**Check 1: vocab → read**
```bash
grep -o '\*\*[^*]*\*\*' src/data/weeks/week_XX/read.js
```
- Count bolded words
- Should match vocab.js word count (or close to it)

**Check 2: read → dictation**
```bash
# Count sentences in read.js content
wc -l src/data/weeks/week_XX/read.js

# Count dictation exercises
grep -c '"id":' src/data/weeks/week_XX/dictation.js
```
- Dictation exercise count should match sentence count

**Check 3: writing keywords**
```bash
grep 'keywords' src/data/weeks/week_XX/writing.js
```
- Keywords should be from vocab.js

### Phase 3: Theme Consistency

Check all 14 files mention same theme:
```bash
grep -i 'emotion\|happy\|sad' src/data/weeks/week_04/*.js
```
(Adjust search term for week's theme)

## 🔧 TROUBLESHOOTING

### Problem 1: dictation.js doesn't match read.js
**Solution**:
1. Re-read read.js content_en field
2. Extract sentences (split by '. ')
3. Create 1 dictation exercise per sentence
4. Check sentence count matches

### Problem 2: read.js doesn't bold vocab words
**Solution**:
1. Re-read vocab.js word list
2. Find each word in read.js content
3. Wrap with **word** syntax
4. Example: "happy" → "**happy**"

### Problem 3: Theme inconsistency across files
**Solution**:
1. Check syllabus_database.js for week's theme
2. Ensure all 14 files use same theme
3. Example: Week 4 = Emotions → All files about feelings

### Problem 4: Syntax errors
**Solution**:
1. Check all quotes are closed
2. Check all brackets match
3. Check commas between array items
4. Run validation command (see Phase 1 above)
