## 3. GRAMMAR.JS (~100 lines)

**Purpose**: Grammar exercises focused on week's target grammar

**Schema**:
```javascript
export default {
  grammar_explanation: {
    title_en: "I like + V-ing (Expressing Preferences)",
    title_vi: "I like + V-ing (Diễn đạt Sở thích)",
    rules: [
      {
        type: "rule",
        icon: "1️⃣",
        rule_en: "Add -ing to verbs after 'like': I like playing",
        rule_vi: "Thêm -ing vào động từ sau 'like': I like playing"
      },
      // 3-5 grammar rules
    ]
  },
  
  exercises: [
    // 30% AFFIRMATIVE (6 exercises)
    {
      id: 1,
      type: "fill",  // Types: "fill", "mc", "unscramble"
      question: "I like _____ (play) games.",
      answer: "playing",
      hint: "play + ing"
    },
    {
      id: 2,
      type: "mc",
      question: "She likes _____ books.",
      options: ["read", "reading", "reads"],
      answer: "reading",
      hint: "like + V-ing"
    },
    
    // 30% NEGATIVE (6 exercises)
    {
      id: 7,
      type: "fill",
      question: "I don't like _____ (run).",
      answer: "running",
      hint: "don't like + V-ing"
    },
    
    // 40% QUESTIONS (8 exercises)
    {
      id: 13,
      type: "fill",
      question: "_____ you like playing?",
      answer: "Do",
      hint: "Do + you"
    },
    {
      id: 15,
      type: "unscramble",
      question: "Order:",
      words: ["like", "Do", "you", "drawing"],
      answer: "Do you like drawing?",
      hint: "Do you like"
    }
  ]
};
```

**Rules**:
- **20 exercises total**
- **30% affirmative** (6 exercises)
- **30% negative** (6 exercises)
- **40% questions** (8 exercises)
- Exercise types:
  - `fill`: Fill in the blank
  - `mc`: Multiple choice (3 options)
  - `unscramble`: Word order
- Grammar topic from syllabus_database.js

**Exercise design**:
- Progressive difficulty (easier first)
- Use vocab words from vocab.js
- Clear, simple instructions
- Helpful hints

## 10. MINDMAP.JS (~50 lines)

**Purpose**: Sentence building with stems and branches

**Schema**:
```javascript
const mindMapContent = {
  centerStems: [
    {
      text: "I like ___.",  // Sentence stem with blank
      audio: "/audio/weekX/mindmap_stem_1.mp3"
    },
    {
      text: "I feel ___ when I ___.",
      audio: "/audio/weekX/mindmap_stem_2.mp3"
    },
    // 6 sentence stems
  ],
  
  branchLabels: {
    "I like ___.": [
      { text: "playing games", audio: "/audio/weekX/mindmap_branch_1.mp3" },
      { text: "reading books", audio: "/audio/weekX/mindmap_branch_2.mp3" },
      // 6 branches per stem
    ],
    "I feel ___ when I ___.": [
      { text: "happy when I play", audio: "/audio/weekX/mindmap_branch_7.mp3" },
      // 6 branches
    ],
    // Branches for each stem
  }
};

export default mindMapContent;
```

**Rules**:
- **6 sentence stems** (centerStems)
- **6 branches** per stem (36 total branches)
- Stems use `___` for blanks
- Branches complete the stems
- Use grammar pattern from grammar.js
- Use vocab words from vocab.js
