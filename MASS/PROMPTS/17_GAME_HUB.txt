## 🎯 GAME HUB PHILOSOPHY

**Goal**: Make Logic Lab feel like **interactive puzzles**, NOT a dry math test

**Key**: **Story-based context** for every puzzle

**Why**: Children ages 6-10 engage better with stories than abstract equations

---

## 📋 LOGIC.JS SCHEMA

```javascript
export default {
  puzzles: [  // ⬅️ CRITICAL: Use "puzzles" NOT "problems"
    {
      id: NUMBER,
      type: "math" | "logic" | "pattern" | "spatial",
      title_en: "string",          // Engaging title (e.g., "The Cookie Jar")
      title_vi: "string",
      
      // CRITICAL: Full story context required
      question_en: "string",       // Must be story-based, NOT bare equation
      question_vi: "string",
      
      // CRITICAL: Audio URL for question narration (MANDATORY)
      audio_url: "string",         // e.g., "/audio/week4/logic_1.mp3"
      
      // CRITICAL: Answer must include units
      answer: ["string"],          // e.g., "5 cookies", NOT just "5"
      
      hint_en: "string",
      hint_vi: "string"
    }
  ]  // EXACTLY 5 puzzles per week
};
```

---

## 🚨 MANDATORY REQUIREMENTS

### 1. Exactly 5 Puzzles
- No more, no less
- Each week has 5 puzzles
- Mix different types

### 2. Use "puzzles" Key (NOT "problems")
```javascript
// ✅ CORRECT:
export default {
  puzzles: [...]
};

// ❌ WRONG (Component can't find data):
export default {
  problems: [...]
};
```

**Why**: Component reads `data.puzzles`, not `data.problems`

---

### 3. Full Story Context
Every puzzle MUST have:
- Characters (You, Tom, Lisa, Mom, Dad)
- Objects (apples, pencils, cookies, toys)
- Action (give, eat, buy, find)
- Question (How many...?, Who has more...?)

**Min length**: 15 words

---

### 4. Units in Answers
```javascript
// ✅ CORRECT:
answer: ["5 cookies", "five cookies", "5 cái bánh"]

// ❌ WRONG:
answer: ["5"]  // No unit!
```

**Why**: Teaches students to include units in real-world problem-solving

---

### 5. Audio URL (Mandatory)
```javascript
// ✅ CORRECT:
audio_url: "/audio/week4/logic_1.mp3"

// ❌ WRONG (missing audio):
// No audio_url field
```

**Path format**: `/audio/week<ID>/logic_<puzzle_id>.mp3`

## 🎯 WHY STORY-BASED MATTERS

### Pedagogical Benefits:
1. **Contextual Learning**: Children learn math in real-world situations
2. **Language Integration**: Combines English vocabulary with math concepts
3. **Engagement**: Stories are more interesting than abstract equations
4. **Comprehension**: Context helps students understand what the problem asks
5. **Retention**: Story-based problems are more memorable

### Example Comparison:

**Abstract (Bad)**:
```
Question: "5 + 3 = ?"
→ Student thinking: "I need to add numbers."
```

**Story-based (Good)**:
```
Question: "You have 5 toy cars. Your friend gives you 3 more. How many toy cars do you have now?"
→ Student thinking: "I start with 5 cars. My friend gives me 3. Now I have 5 + 3 = 8 cars!"
```

**Result**: Student understands WHY they're adding, not just HOW to add.

## 🚀 INTEGRATION WITH GAME HUB UI

**Component**: `src/modules/stations/LogicLab.jsx`

**How it works**:
1. Component reads `data.puzzles` array
2. Displays 5 puzzles as cards
3. Each card shows title, plays audio, shows question
4. Student types answer
5. Component checks answer against all formats in `answer` array
6. Shows hint if student clicks "Hint" button

**Audio playback**:
- Automatically plays when card is displayed
- Can replay by clicking audio icon
- Uses `audio_url` path from puzzle data
