## 2. Verbatim Description from Cambridge Handbook (pp. 29–30)

\`\`\`text
Part 2: Information Exchange
Format: The examiner and the candidate take turns to ask and answer questions using two information cards.
Procedure:
1. The examiner gives the candidate two cards: one card contains factual information about a person, place, or event (Card A), and the other card contains five question prompt cues (Card B).
2. The examiner holds the complementary pair of cards.
3. In Phase 1, the examiner asks five questions using the question cues on their card, and the candidate answers using the information on Card A.
4. In Phase 2, roles are reversed: the candidate asks five questions using the cues on Card B, and the examiner answers using the information on their card.
Number of cues / questions per card: Exactly 5 items.
Time allowed: 3–4 minutes.
\`\`\`
