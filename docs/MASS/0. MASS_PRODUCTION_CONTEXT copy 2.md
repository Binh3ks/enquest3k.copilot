## Key Issues Addressed

1. **Audio Generation Bugs:**
  - TTS was reading markdown markers (`**`, `___`) in source text, causing unnatural audio.

  - Week 2 `ask_ai.js` prompts did not teach question formation; context sometimes revealed the answer or used forbidden patterns.
  - *Fix:* Both advanced and easy prompts for Week 2 were rewritten to use "Ask ..." context and canonical A0 questions; audio regenerated.

## Pipeline Improvements

1. **Master Prompt Update:**
  - `ENGQUEST MASTER PROMPT V26-FINAL.txt` now includes "ASK-AI AUTHORING RULES (NEW - Enforced)" for clear content guidelines.

2. **Automated Validation:**
  - New script `tools/validate_ask_ai.js` checks all `ask_ai.js` files for rule compliance (context form, word count, forbidden patterns, etc.).
  - This validator is now called in `tools/mass_production_final.sh` before audio generation. The pipeline aborts if validation fails, preventing bad prompts from being processed.

## 1. PROJECT OVERVIEW

### 1.1 Mission
Generate **54 weeks** of ESL content for Vietnamese children (ages 6-10) to achieve **B1+ (IELTS 5.0-5.5)** after 3 years.

### 1.2 Architecture
```
EngQuest3k/
├── Frontend: React + Vite + Zustand
├── Backend: Node.js + Express + PostgreSQL
├── AI Tutor: Ms. Nova (Gemini API)
└── Content: 156 weeks (54 in Phase 1)
```

### 1.3 Content Strategy
**Dual-Mode System:**
- **EASY MODE**: Personal, concrete (6-8 sentences, Tier 1 vocab)
- **ADVANCED MODE**: Global, abstract (10-11 sentences, Tier 2-3 vocab)

**Total Vocabulary per Week:**
- `vocab.js`: 10 core words
- `word_power.js`: 3 collocations
- `explore.js`: 10 CLIL words (MUST be different from read.js)
- **TOTAL: 23 words/week**

- ✅ **Max 2 syllables** preferred

- ✅ Subject + Verb: "I have", "I like", "I go"

- ❌ **NO**: past tense, future tense, conditionals, passive voice

#### Sentences
- ✅ **Max 6-8 words** per sentence (Easy: 6, Advanced: 8-10)
- ✅ Simple structure: S + V + O
- ❌ **NO**: compound sentences with "because", "although", "however"

### 4.2 Ask AI Station - A0 Question Patterns

**✅ ALLOWED:**

**❌ FORBIDDEN:**
```javascript
"How do they go to school?"     // A1 - 3rd plural + do
"What does it do?"              // A1 - does + base verb
"Where can I find...?"          // A1 - modal + find
"Why is/are...?"                // A1 - causation
```
