## Free Talk 3.0 Critical Bug Fixes - Case-Sensitivity & Translation Detection (DEPRECATED - See Above)

### Issues Discovered During Testing

**User Complaint**: "Sao mày vẫn cứ giữ nội dung cũ thế. Xóa hết mấy cái prompt câu hỏi cũ đi"
- Free Talk 3.0 UI implemented (game selection cards, action bar) but AI still using old prompts
- User tested and showed conversation logs proving AI broken:
  - Asked "whale là gì" → AI responded "Whale là gì! What is your favorite animal?" (didn't translate!)
  - Clicked "START_GAME: I Spy" → AI said "You are playing I Spy! What is your favorite game?" (generic response, no game start!)
  - After asking for translation, AI said "You like deer! What is your favorite animal?" (wrong mode!)

### Root Causes Identified

1. **Case-Sensitivity Bug (CRITICAL)**:
   - FreeTalkTab.jsx sends: `START_GAME: I Spy` (UPPERCASE)
   - tutorPrompts.js checks: `userMessage.startsWith('start_game:')` (lowercase)
   - Result: **NEVER MATCHES** → AI falls back to generic opening greeting

2. **Translation Detection Too Narrow**:
   - Only detected "tiếng anh là gì" (full phrase)
   - Didn't detect standalone "là gì" pattern (whale là gì, dog là gì)
   - Didn't detect AI's own response "What word?" for continuation

3. **Translation Continuation Broken**:
   - User: "Translate this..." → AI: "What word?"
   - User: "deer" → AI mode resets to OPENING TURN instead of staying in translation
   - Condition only checked `lastAIMessage.includes('what do you want to translate')` but AI said "What word?"

### Fixes Implemented

#### Fix 1: Case-Insensitive Detection (tutorPrompts.js)
```javascript
// BEFORE (BROKEN)
if (userMessage.startsWith('start_game:')) {

// AFTER (FIXED)
if (userMessage.toLowerCase().startsWith('start_game:')) {
```

**Impact**: START_GAME, START_ROLEPLAY now detected regardless of case

#### Fix 2: Added "là gì" Detection
```javascript
// Added standalone "là gì" pattern
if (userMessage.includes('translate') || 
    userMessage.includes('là gì') ||  // ← NEW
    lastAIMessage.includes('what word') ||  // ← NEW
    lastAIMessage.includes('what do you want to translate')) {
```

**Impact**: Now detects "whale là gì", "dog là gì" and continues translation mode after "What word?"

#### Fix 3: Explicit Anti-Old-Prompt Instructions
```javascript
🚨 CRITICAL: When translating, JUST TRANSLATE! Do NOT say:
❌ "You like deer!"
❌ "What is your favorite animal?"

✅ CORRECT: "Deer is a forest animal! 🦌 D-E-E-R."

Example for "deer" (after you asked "What word?"):
{
  "ai_response": "A deer is a forest animal with antlers! 🦌 D-E-E-R. Deer are gentle and fast! What other animals do you want to know?",
  "suggested_hints": ["bear", "fox", "rabbit", "wolf", "squirrel"]
}
```

**Impact**: AI explicitly forbidden from using old "You like X! What is your favorite?" patterns

## 4. MASTER PROMPT V24.2 RULES

### 4.1 CEFR A0/A0++ Guidelines (Phase 1: Weeks 1-54)

#### Vocabulary
- ✅ **Tier 1 only**: concrete nouns, basic verbs
- ✅ **Max 2 syllables** preferred
- ✅ Examples: book, pen, school, happy, go, see, have
- ❌ NO: abstract concepts, academic terminology (save for explore.js)

#### Grammar
- ✅ **Present Simple ONLY**
- ✅ Subject + Be: "I am", "She is", "They are"
- ✅ Subject + Verb: "I have", "I like", "I go"
- ✅ Questions: "What is...?", "Where is...?", "Can I...?"
- ❌ **NO**: past tense, future tense, conditionals, passive voice

#### Sentences
- ✅ **Max 6-8 words** per sentence (Easy: 6, Advanced: 8-10)
- ✅ Simple structure: S + V + O
- ❌ **NO**: compound sentences with "because", "although", "however"

### 4.2 Ask AI Station - A0 Question Patterns

**✅ ALLOWED:**
```javascript
"What is this?"
"Where is the pen?"
"Is this a book?"
"Can I play?"
"Do you like it?"
"Who is she?"
```

**❌ FORBIDDEN:**
```javascript
"How do they go to school?"     // A1 - 3rd plural + do
"What does it do?"              // A1 - does + base verb
"Where can I find...?"          // A1 - modal + find
"Why is/are...?"                // A1 - causation
"How many/much...?"             // A1 - quantifiers
```

### 4.3 Context Length Rules

| Component | Easy Mode | Advanced Mode |
|-----------|-----------|---------------|
| ask_ai context | 5-6 words | 8-10 words |
| read.js sentences | 8 sentences (5-7 words each) | 10-11 sentences (8-10 words each) |
| vocab definition | "You sit on it." | "A piece of furniture for sitting." |
| grammar vocab | concrete (pen, book) | academic (student, teacher) |

### 4.4 Dual-Mode Differentiation

| Aspect | Easy Mode | Advanced Mode |
|--------|-----------|---------------|
| **Context** | Personal (me, family, home) | Global (world, history, science) |
| **Vocabulary** | Tier 1 (cat, dog, happy) | Tier 2-3 (scientist, observe, discover) |
| **Sentence Structure** | S + V (+ O) | S + V + O + Prep phrase |
| **Grammar Vocab** | Names (Lily, Tom) | Academic (student, classroom) |

## 10. TROUBLESHOOTING GUIDE

### 10.1 Common Errors & Solutions

#### Error: Week not showing in dropdown
**Symptom:** Week 2 generated but doesn't appear in UI

**Cause:** Not registered in database

**Solution:**
```bash
node tools/update_db_smart.js 2
```

#### Error: ask_ai context too long
**Symptom:** Validation fails on ask_ai.js

**Example:**
```
❌ ask_ai: Prompt 3 context too long (12 words, max 10)
```

**Solution:** Edit `ask_ai.js` manually:
```javascript
// ❌ WRONG (12 words):
context_en: "You are at the library and want to find a specific book."

// ✅ CORRECT (8 words):
context_en: "You want a book. Ask where."
```

#### Error: explore.js has duplicate words
**Symptom:** Validation fails on word uniqueness

**Example:**
```
❌ explore: 5 duplicate words with read.js (max 2)
```

**Solution:** Regenerate explore.js with instruction:
```
"CRITICAL: explore.js must have 10 NEW bold words.
DO NOT repeat words from read.js: [list of 10 words]
Choose a different CLIL topic."
```

#### Error: grammar.js wrong count
**Symptom:** Not exactly 20 exercises

**Solution:** Add/remove exercises to reach exactly 20

#### Error: GPT-4 API key invalid
**Symptom:** generate_week.js fails immediately

**Solution:**
1. Check `API keys.txt`
2. Verify key format: `sk-...`
3. Set environment variable:
```bash
export OPENAI_API_KEY="sk-..."
node tools/generate_week.js 2
```

#### Error: Audio files not playing
**Symptom:** UI renders but no sound

**Cause:** Audio not generated or wrong path

**Solution:**
```bash
# Regenerate audio
node tools/batch_manager.js 2 2

# Check files exist
ls public/audio/week2/*.mp3 | wc -l
# Should show: 65 files
```

#### Error: Images not displaying
**Symptom:** Broken image icons

**Solution:**
```bash
# Regenerate images

# Check files exist
ls public/images/week2/*.jpg | wc -l
```
