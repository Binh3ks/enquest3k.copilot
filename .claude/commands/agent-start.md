# Custom Command: /agent-start

## Description
Khoi dong phien lam viec moi, nap toan bo context va memory cua AgentOS.

## Instructions
When this command is run, you MUST execute these steps in order:
1. Read and acknowledge `.ai/AGENTOS_SPEC.md`.
2. Read `.ai/memory/CURRENT.md` to update your internal state on the project status.
3. Read `.ai/tasks/ACTIVE.md` to see what needs to be worked on.
4. Read `CLAUDE.md` to understand available production tools.
5. Output a short summary confirming you are fully initialized and ready.
