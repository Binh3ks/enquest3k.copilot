🧹 Clear All Cache & Storage

Vấn đề: Browser đang cache audio & chat messages cũ (giọng cũ + JSON hiển thị sai)

Giải pháp: Xóa toàn bộ:

  • ✅ localStorage (chat history, session data)
  • ✅ sessionStorage (temporary data)
  • ✅ IndexedDB (offline database)
  • ✅ Service Worker cache
  • ✅ Browser cache (audio files)
Manual method (if button doesn't work):
1. Open DevTools (Cmd+Option+I)
2. Application tab → Clear storage
3. Check all boxes → Clear site data
4. Hard reload (Cmd+Shift+R)
