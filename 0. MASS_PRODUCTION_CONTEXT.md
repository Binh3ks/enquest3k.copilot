# Mass Production Context - January 15, 2026

This document summarizes the key fixes and improvements made to the mass production pipeline.

## Key Issues Addressed:

1.  **Audio Generation Bugs:**
    *   **Problem:** The Text-to-Speech (TTS) engine was reading out markdown markers (`**`, `___`) present in the source text, causing unnatural audio.
    *   **Fix:** The `tools/generate_audio_final.py` script was updated to automatically remove these markers before sending the text to the TTS API.

2.  **Missing Mindmap Audio URLs:**
    *   **Problem:** The `mindmap.js` files had empty `audio_url` fields, which would cause the browser to fall back to its own, lower-quality TTS.
    *   **Fix:** A new script, `tools/update_mindmap_audio_urls.js`, was created. It automatically generates the correct audio URL for each mindmap node based on its text and adds it to the file. This script was integrated as **Step 5.5** in the main pipeline.

3.  **Incorrect Ask-AI Prompts:**
    *   **Problem:** The `ask_ai.js` prompts for Week 2 were not correctly teaching question formation. The context often gave away the answer or used forbidden question patterns.
    *   **Fix:** The prompts for Week 2 (both advanced and easy modes) were manually rewritten to follow the golden standard: the `context_en` now instructs the user to ask a question (e.g., "Ask what it is."), and the `answer` array contains the target A0-level question. Audio was regenerated for these prompts.

## Pipeline Improvements:

To prevent `Ask-AI` prompt issues from happening again, the following process improvements were implemented:

1.  **Master Prompt Update:**
    *   The `ENGQUEST MASTER PROMPT V26-FINAL.txt` was updated with a new section: **"ASK-AI AUTHORING RULES (NEW - Enforced)"**. This provides clear guidelines for content creators.

2.  **Automated Validation:**
    *   A new validation script, `tools/validate_ask_ai.js`, was created.
    *   This script automatically checks all `ask_ai.js` files against the new authoring rules (e.g., context must contain "ask", must not contain a direct question, word count limits, etc.).
    *   This validator has been added to the `tools/mass_production_final.sh` script. It runs **before Step 5 (Audio Generation)**. If validation fails, the entire production pipeline will stop, preventing bad content from being processed and assets from being generated.
